## このパートの総復習 {#recap}

GSAP で、スクロール連動や順番のある演出を作れるようになりました。要点を並べます。

- **useGSAP** … `useGSAP(() => { ... }, { scope })` の中に `gsap.to` / `from` / `fromTo` を書く。後片付けと StrictMode は自動、`scope` でセレクタを箱の中に限定。
- **timeline** … `gsap.timeline()` に繋げて順番に再生。position パラメータ（`'-=0.2'` / `'+=0.1'`）で重なりと間を作る。`ref` に覚えれば `restart` などで操作できる。
- **ScrollTrigger** … `registerPlugin` してから `scrollTrigger` を足す。`start` / `end` の読み方、`scrub`（同期）・`toggleActions`（見えたら再生）・`pin`（固定）・`markers`（デバッグ）。
- **matchMedia** … `gsap.matchMedia()` で reduced-motion に配慮。動きだけ消し、情報は残す。

## 次に読むと良いもの {#next}

これで **GSAP** は一通りです。`useGSAP` の基本から、タイムライン、ScrollTrigger まで、スクロール連動の演出を自分で組めるようになりました。

同じ **ライブラリ編** には、**Swiper**（スライダー / カルーセル）、**Tailwind**（ユーティリティ CSS）、**React Icons**（アイコン）、**Lenis**（スムーススクロール、GSAP と相性◎）などを、順次追加していきます。作りたい UI が先にあるなら、**[レシピ](/recipes/modal)** からの逆引きも近道です。

<SummaryBox>

- `useGSAP` に書く／`timeline` で順番と重なり／`ScrollTrigger` でスクロール連動／`matchMedia` で配慮
- 単純な動きは Framer Motion、スクロール連動や込み入った演出は GSAP
- 次は Swiper・Tailwind など、必要なライブラリを引きながら

</SummaryBox>
