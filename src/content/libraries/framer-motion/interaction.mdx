## whileHover / whileTap {#while}

`initial` / `animate` が「マウント時の動き」なのに対し、**`whileHover`** と **`whileTap`** は「その操作をしている**間**」の状態です。手を離す・マウスを外すと、自動で元に戻ります。

```tsx
import { motion } from 'motion/react'

<motion.button
  whileHover={{ scale: 1.06 }} // 乗せている間、少し大きく
  whileTap={{ scale: 0.94 }} // 押している間、少し小さく
  transition={{ type: 'spring', stiffness: 400, damping: 20 }}
>
  乗せる・押す
</motion.button>
```

- **`whileHover={{ scale: 1.06 }}`** … マウスが乗っている間だけ 1.06 倍。外すと戻る。
- **`whileTap={{ scale: 0.94 }}`** … 押している間だけ 0.94 倍。離すと戻る。

「押したら少し沈む」は、**押せたことが指に伝わる**フィードバックになります。CSS の `:hover` に近いですが、`spring` で戻るので、より柔らかい質感になります。

## やりすぎない {#restraint}

反応は**小さく**が基本です。`scale: 1.06`（6%）くらいで十分。`1.5` のように大きく動かすと、うるさく、押しづらくなります。「言われないと気づかないくらい」がちょうどいい塩梅です。

## うまくいかないとき {#trouble}

- **戻らない** … `whileHover` / `whileTap` は「している間」の状態です。`animate` で固定していないか確認します。
- **スマホで whileHover が効かない** … タッチにはホバーがありません。スマホでも要る反応は `whileTap` にします。
