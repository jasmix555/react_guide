## 動きには「理由」を持たせる {#why}

大事な前提です。**アニメーションは、多ければ良いものではありません**。あちこちが常に動いていると、うるさく、読みづらく、酔う人もいます。動きを付けるときは、必ず**理由**を持たせます。

- **注目させる** … 新しく出た要素にフワッと出て、目を引く。
- **状態の変化を伝える** … 追加・削除・切り替えを、パッではなく滑らかに見せる。
- **操作に反応する** … 押した・乗せたことを、動きで返す。

「なんとなくカッコいいから」で動かさない——これが、うるさくならないコツです。そして、**動きが苦手な人のための配慮**（`prefers-reduced-motion`）も、このパートで最初から扱います。

## このパートの進み方 {#roadmap}

1. **motion の基本** — `motion.div` と `initial` / `animate` / `transition`。
2. **ホバー・タップ** — `whileHover` / `whileTap` で操作に反応する。
3. **動きを減らす設定** — `useReducedMotion` で、苦手な人に配慮する。
4. **スクロールと stagger** — 見えたら出す、少しずつ出す。
5. **出入りのアニメ** — `AnimatePresence` で、消えるときも滑らかに。
6. **通し課題** — `ProductCard` の一覧に動きを付ける。

各ページに**コード全文**と、動く**デモ**を用意しています。実際に触って、動きの気持ちよさと「やりすぎ」の境目を確かめてください。
