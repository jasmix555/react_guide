## このパートの総復習 {#recap}

直 import だった一覧を、本物の通信で動くようにしました。要点を並べます。

- **import と fetch** … `import` は焼き込み（一瞬・固定）、`fetch` は通信（時間・失敗・最新）。
- **fetch の骨格** … `await fetch(url)` → **`if (!res.ok) throw`** → `await res.json()`。404 でも fetch は失敗しないので `res.ok` を自分で見る。
- **どこで呼ぶか** … render 本体は無限ループ。`useEffect(() => {...}, [])` で 1 回だけ。後片付けで `ignore = true`。
- **3 状態** … `status` を `'loading' | 'error' | 'success'` の union で持ち、`try` / `catch` で振り分け、画面で出し分ける。
- **カスタムフック** … 取得を `useProducts()`（`use` で始まる関数）にまとめ、`{ products, status }` を返して使い回す。

「待つ・失敗する」を 3 状態で扱う——この形は、どんな通信でも同じです。

## ここまでで React のコアは修了 {#next}

データも本物の通信で取れるようになりました。これで **React のコア**（環境構築 → JavaScript → コンポーネント → state → スタイリング → TypeScript → ルーティング → データ取得）を一通り終えました。`my-shop` は、**自分の手で組んだ・動く・型で守られた・複数ページの・通信するアプリ**です。「どう書くか」は、もう身についています。

この先は **ライブラリ編**（別タブ）へ。よく使うライブラリを、実際のプロジェクトにどう入れて・どう使うかを、ライブラリごとに深掘りします。まずは **Framer Motion** で、カードがふわっと出る「気持ちよさ」を足すのがおすすめです。作りたい UI が先にあるなら、**[レシピ](/recipes/modal)** からの逆引きも近道です。
