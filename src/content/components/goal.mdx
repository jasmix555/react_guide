## 完成形を先に見る {#goal}

このパートのゴールは、下のような **商品一覧** です。これは 1 枚の巨大な HTML ではなく、**「商品カード」という部品を 6 個並べたもの**です。

<Demo title="商品一覧（このパートのゴール）">
  <ProductListDemo />
</Demo>

同じ形のカードが商品の数だけ並んでいます。React では、このカードを **1 つの部品として作り**、あとはデータの数だけ**繰り返し並べる**——という作り方をします。LP を 1 枚ずつ手で組んでいたのとは、発想が変わります。

## React は「部品を組み合わせて画面を作る」 {#idea}

React の一番の考え方は、**画面を小さな部品に分けて、それを組み合わせる**ことです。ボタン、商品カード、検索ボックス……それぞれを独立した部品（**コンポーネント**）として作り、レゴのように組み立てて 1 つの画面にします。

<Callout type="analogy">

LP 制作で使っていた PHP の `include`（ヘッダーやフッターを別ファイルにして読み込む）を思い出してください。あれをもっと推し進めて、**ボタン 1 個・カード 1 枚まで部品にする**のが React です。しかも部品に値（`include` でいう引数）を渡して、中身を変えられます。

</Callout>

一度部品を作れば、**直すのは 1 か所**で済みます。「全カードの価格の位置を変えたい」なら、カード部品を 1 回直すだけ。100 枚あっても全部に反映されます。これが、同じ見た目を手でコピーしていた作り方との決定的な違いです。

## このパートの進み方 {#roadmap}

上から順に、少しずつ部品を組み立てていきます。

1. **JSX** — React の中で HTML のような書き方をする仕組み。
2. **初めてのコンポーネント** — 部品を 1 つ作って画面に出す。
3. **props** — 部品に値を渡して、中身を変える。
4. **一覧表示（map）** — データの数だけ部品を並べる。`key` の話。
5. **条件で出し分け** — 在庫の有無などで表示を変える。
6. **イベント** — クリックに反応する。
7. **再利用（variant）** — 見た目違いを 1 つの部品にまとめる。

最後まで行くと、冒頭のデモのような一覧を、自分の手で組み立てられるようになります。
