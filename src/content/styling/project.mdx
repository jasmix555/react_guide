## 作るもの {#goal}

ゴールは、Part 5 の最初に見たあのカード一覧です。画像・カテゴリ・価格・お気に入り・売り切れ表示がそろい、画面幅に応じて折り返します。ここまでのページの内容を、実際のファイルに組み上げます。

## フォルダ構成 {#tree}

`my-shop` は、この形にします。色のトークンは 1 枚にまとめ、`main.tsx` で 1 度だけ読み込みます。

```
my-shop/src/
├─ main.tsx                       ← styles/tokens.scss を import
├─ App.tsx                        ← 一覧（グリッド）
├─ App.module.scss                ← 一覧のレイアウト
├─ styles/
│  └─ tokens.scss                 ← デザイントークン（--c-*）
├─ components/ProductCard/
│  ├─ ProductCard.tsx
│  └─ ProductCard.module.scss
└─ data/products.json
```

## 1. トークンを 1 枚に {#tokens}

## 3. ProductCard.tsx（全文） {#card-tsx}

`clsx` で条件付きクラス、`useState` でお気に入り、売り切れは条件付きレンダリングです。

```tsx title="src/components/ProductCard/ProductCard.tsx（全文）"
import clsx from 'clsx'
import { useState } from 'react'

import styles from './ProductCard.module.scss'

interface ProductCardProps {
  name: string
  price: number
  category: string
  imageUrl: string
  inStock: boolean
}

export function ProductCard({ name, price, category, imageUrl, inStock }: ProductCardProps) {
  const [fav, setFav] = useState(false)

  return (
    <article className={styles.card}>
      <div className={styles.media}>
        <img src={imageUrl} alt={name} loading="lazy" />
        {!inStock && <span className={styles.sold}>売り切れ</span>}
      </div>

      <div className={styles.body}>
        <span className={styles.category}>{category}</span>
        <h3 className={styles.name}>{name}</h3>
        <div className={styles.row}>
          <span className={styles.price}>{price.toLocaleString()}円</span>
          <button
            type="button"
            className={clsx(styles.fav, fav && styles.active)}
            aria-pressed={fav}
            aria-label="お気に入り"
            onClick={() => setFav((f) => !f)}
          >
            {fav ? '♥' : '♡'}
          </button>
        </div>
      </div>
    </article>
  )
}
```

## 4. 一覧をレスポンシブに並べる {#list}

一覧のグリッドは `App.module.scss` に。`auto-fill` + `minmax` で、画面幅に応じて列数が自動で変わります。

```scss title="src/App.module.scss"
.list {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
  gap: 16px;
  padding: 16px;
}
```

```tsx title="src/App.tsx（完成）"
import products from './data/products.json'

import styles from './App.module.scss'
import { ProductCard } from './components/ProductCard/ProductCard'

function App() {
  return (
    <div className={styles.list}>
      {products.map((product) => (
        <ProductCard
          key={product.id}
          name={product.name}
          price={product.price}
          category={product.category}
          imageUrl={product.imageUrl}
          inStock={product.inStock}
        />
      ))}
    </div>
  )
}

export default App
```

保存すると、素の一覧が最初に見た**カード一覧**になります。ウィンドウ幅を変えると列数が変わり、OS をダークにすると色が切り替わります。ここまでで、このパートの内容が全部つながりました。

## まとめ {#summary}

<SummaryBox>

- 色は `styles/tokens.scss` に集約し、部品は `var(--c-*)` を参照（ダークは値の差し替えだけ）
- `ProductCard` は入れ子・`&`・`clsx` の条件付きクラスで組む
- 一覧は `grid` の `auto-fill` + `minmax` でレスポンシブに折り返す

</SummaryBox>
