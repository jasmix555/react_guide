## リテラル型：特定の値だけ許す {#literal}

`string` は「どんな文字列でも」ですが、**特定の文字列だけ**に限りたいことがあります。`variant` に入れてよいのは `'primary'` か `'secondary'` だけ、のように。そのときは、値そのものを型にします（リテラル型）。

```ts
type Variant = 'primary' | 'secondary' | 'ghost'
```

```ts
type Variant = 'primary' | 'secondary' | 'ghost'
//             ↑           ↑
//             │           └─ | は「または」
//             └─ この 3 つの文字列のうち、どれか 1 つだけ
```

`|` は「または」。`Variant` 型の変数には、この 3 つ以外を入れられません。[button-variants のページ](/guide/components/button-variants)で使ったのがこれです。

## union 型：どれか 1 つ {#union}

`|` でつなぐのは文字列だけでなく、型同士でもできます。「`string` または `number`」「`Product` または `null`」のように、**複数の型のどれか**を表せます。これを union（合併）型と呼びます。

```ts
type Id = string | number // 文字列 または 数値
```

React でよく出るのが **`X | null`** です。「まだ選ばれていないなら `null`、選ばれたら `Product`」のような state を表します。

```tsx
// 選択中の商品。まだ無ければ null
const [selected, setSelected] = useState<Product | null>(null)
```

## narrowing：if で型を絞る {#narrowing}

`Product | null` のような union は、そのままでは中身を使えません（`null` かもしれないから）。`if` でチェックすると、TypeScript は**その先で型を絞り込んで**くれます。これを narrowing（絞り込み）と呼びます。

```tsx
function label(selected: Product | null): string {
  if (selected === null) {
    return '未選択'
  }
  // ここから先、selected は Product に絞られている（null ではない）
  return selected.name
}
```

`if (selected === null) return ...` を通ったあとは、TypeScript は「`selected` はもう `null` ではない＝`Product`」と分かるので、`selected.name` が安全に書けます。

## わざと壊す：union にない値を渡す {#break}

リテラル union が守る様子を見ます。`'primary' | 'secondary'` の型に、無い値を入れてみます。

```ts title="union にない値"
type Variant = 'primary' | 'secondary'

const v: Variant = 'primani' // ← 打ち間違い
```

`'primani'` に赤い波線が付き、こう出ます。

```
Type '"primani"' is not assignable to type 'Variant'.
```

「`'primani'` は `Variant`（primary か secondary）には入れられません」。正しい綴りにすれば消えます。もし型が `string` だったら、この打ち間違いは素通りしていました。

## 書き方カタログ：union とリテラル {#catalog}

```ts
type Variant = 'primary' | 'secondary' // リテラル union
type Id = string | number // 型の union
type Nullable = Product | null // 値 または 無し

// narrowing
function f(x: string | null) {
  if (x === null) return 0
  return x.length // ここでは x は string
}
```

## うまくいかないとき {#trouble}

- **`'X' is possibly 'null'`** … `X | null` の中身を、`null` チェックせずに使っています。`if (x === null)` で絞ってから使います。
- **リテラルが効かない** … 型が `string` になっていないか確認します。候補を固定するには `'a' | 'b'` と書きます。
