- `sass` を入れて、部品用の `.module.scss` を作る
- `import styles` して `className={styles.card}` で当てる基本の形

## まず sass を入れる {#install}

SCSS はブラウザがそのまま読めないので、CSS へ変換する `sass` が要ります。まだ入れていなければ、`my-shop` で次を実行します（詳しくは[「sass を入れる」](/libraries/sass)）。

```bash
npm install -D sass
```

Vite は `sass` が入っていれば `.scss` を自動で認識します。設定ファイルは要りません。

## 部品用の .module.scss を作る {#create}

`ProductCard` 専用のスタイルファイルを作ります。ファイル名は **`.module.scss`** で終わらせるのが約束です。`src/components/ProductCard/ProductCard.module.scss` を新規作成してください。

```scss title="src/components/ProductCard/ProductCard.module.scss（新規作成）"
.card {
  border: 1px solid #e5e7eb;
  border-radius: 12px;
  overflow: hidden;
  background: #fff;
}

.body {
  padding: 12px;
}

.name {
  margin: 0;
  font-weight: 600;
}

.price {
  font-weight: 700;
}
```

（色は後のページで**デザイントークン**にまとめます。まずは直値で進めます。）

## import して当てる {#apply}

このスタイルを `ProductCard.tsx` から読み込み、`className` に割り当てます。読み込みの 1 行を分解します。

```tsx
import styles from './ProductCard.module.scss'
//     ↑                ↑
//     │                └─ 同じフォルダの .module.scss を読む
//     └─ クラス名の入った「オブジェクト」を受け取る（styles.card など）
```

`styles` は、`.module.scss` の中のクラス名を持つオブジェクトです。`styles.card` と書くと、ビルド時に固有化されたクラス名（`ProductCard_card_a1b2c` のような）に変換されます。当てるときは**波かっこ**です。

```tsx
<article className={styles.card}>
//                  ↑
//                  └─ styles.card は固有名。文字列 "card" ではなく波かっこで渡す
```

## ProductCard 全体に付ける {#full}

`ProductCard.tsx` の各要素に `className` を付けた全文がこれです。

```tsx title="src/components/ProductCard/ProductCard.tsx（全文）"
import styles from './ProductCard.module.scss'

interface ProductCardProps {
  name: string
  price: number
  imageUrl: string
}

export function ProductCard({ name, price, imageUrl }: ProductCardProps) {
  return (
    <article className={styles.card}>
      <img src={imageUrl} alt={name} width="100%" />
      <div className={styles.body}>
        <h3 className={styles.name}>{name}</h3>
        <p className={styles.price}>{price.toLocaleString()}円</p>
      </div>
    </article>
  )
}
```

保存すると、素の並びが「枠と余白のあるカード」になります。まだ地味ですが、**スタイルを当てる仕組み**はこれで完成です。あとはこの `.module.scss` に書き足していくだけです。

## うまくいかないとき {#trouble}

- **`styles.card` が `undefined`** … ファイル名が `.module.scss` で終わっているか、クラス名の綴りが合っているか確認します。
- **スタイルが当たらない** … `className={styles.card}`（波かっこ）になっているか、`className="styles.card"`（文字列）でないか確認します。
- **`Preprocessor dependency "sass" not found`** … `sass` の入れ忘れです。`npm install -D sass` を実行します。
