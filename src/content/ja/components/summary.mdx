## このパートの総復習 {#recap}

このパートで、React の**画面を作る基本一式**がそろいました。順に振り返ります。

- **JSX** … HTML に見える JavaScript。波かっこ `{ }` で値や式を差し込む。返す要素は 1 つ（複数は `<>...</>`）。
- **コンポーネント** … JSX を返す関数。名前は大文字始まり。`import` して `<Xxx />` で使う。
- **props** … 部品に値を渡す。分割代入で受け取り、型を付ける。数値は波かっこで渡す。
- **一覧（map と key）** … 配列を `map` で JSX に変えて並べる。`key` には安定した id を使う。
- **条件表示** … `? :` で二択、`&&` で「あるときだけ」。`&&` の左が数値なら `> 0` で真偽値にする。
- **イベント** … `onClick` に関数を渡す（`()` は付けない）。引数はアロー関数で包む。

Part 2 の JavaScript が、そのまま画面作りに効いているのが分かったと思います。`map`・分割代入・三項演算子・`&&`・関数を値として渡す——全部ここで使いました。

## 通し課題：商品一覧を表示する {#project}

通し課題の `my-shop` を、このパートの内容で一歩進めます。次を自分の手でやってみてください。

1. `src/components/ProductCard/ProductCard.tsx` を作り、`name` と `price` を props で受け取って表示する。
2. `App.tsx` で `products.json` を `import` し、`map` で `<ProductCard />` を並べる（`key={product.id}` を忘れずに）。
3. 在庫切れ（`!product.inStock`）のときだけ「売り切れ」を出す。

```tsx title="src/App.tsx（ここまでの到達点）"
import products from './data/products.json'

import { ProductCard } from './components/ProductCard/ProductCard'

function App() {
  return (
    <div>
      <h1>商品一覧アプリ</h1>
      {products.map((product) => (
        <ProductCard
          name={product.name}
          price={product.price}
          inStock={product.inStock}
          key={product.id}
        />
      ))}
    </div>
  )
}

export default App
```

これで、データから商品一覧が並ぶところまで来ました。まだ**見た目は素**で、**押しても何も変わりません**。そこは次のパート以降で足していきます。
