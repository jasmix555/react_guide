- バッククォートを使い忘れたときに起きること

</LearnBox>

## なぜ + での連結をやめるのか {#why}

「`○○ さん` のように、文字列の中に変数を混ぜたい」場面はとても多いです。これまでは `+` でつないでいたかもしれません。

```js
const name = '佐藤'
const message = 'こんにちは、' + name + ' さん'
```

`+` の連結は、変数が増えるほどクォートと `+` が入り混じって読みにくくなります。**テンプレートリテラル**を使うと、これをそのままの見た目で書けます。

<Callout type="analogy">

PHP のダブルクォート文字列 `"こんにちは、$name さん"` で変数がそのまま展開されたのと同じ感覚です。JavaScript では、そのために**バッククォート**という特別なクォートを使います。

</Callout>

## バッククォートと `${}` {#syntax}

文字列を **バッククォート `` ` ``**（キーボードの左上、`Shift` + `@` の隣あたり）で囲むと、中に `` ${変数} `` の形で値を差し込めます。

```js
const name = '佐藤'
const message = `こんにちは、${name} さん`

console.log(message) // こんにちは、佐藤 さん
```

この書き方を、部品に分けて名前を付けます。

```js
   `${name} さん`
// ↑ ↑
// │ └─ ${ } は「差し込み口」。中の name が値に置き換わる
// └─ バッククォート。これで囲むと ${ } が展開される
```

- **`` ` ``（バッククォート）** … 文字列の囲み。これで囲んだときだけ `${ }` が展開される
- **`${ }`** … 差し込み口。中に変数や式を書くと、その値に置き換わる
- **`さん`** … 地の文は、そのまま並べて書ける

`` ${name} `` の部分が、`name` の中身（`'佐藤'`）に置き換わります。`+` もクォートの切り替えも要りません。

<JsNote feature="バッククォートと ${} はセット">

ふつうのクォート `'...'` や `"..."` では、`` ${...} `` は**ただの文字**として扱われ、展開されません。値を差し込みたいときは、必ず**バッククォート `` `...` ``** で囲みます。`` ${...} `` の中には変数だけでなく、`` ${price * 1.1} `` のように計算式も書けます。

</JsNote>

## 改行もそのまま書ける {#multiline}

バッククォートの中では、改行もそのまま書けます。`\n` を書く必要がありません。

```js
const name = '佐藤'
const text = `こんにちは、${name} さん。
本日はご来店ありがとうございます。`
```

書いたとおりに改行が入ります。

## わざと壊す：ふつうのクォートだと展開されない {#break-wrong-quote}

一番ありがちなミスが、**バッククォートのつもりでふつうのクォートを使ってしまう**ことです。コンソールで見比べます。

```js
const name = '佐藤'

console.log('こんにちは、${name} さん')
// → こんにちは、${name} さん   ← そのまま出てしまう

console.log(`こんにちは、${name} さん`)
// → こんにちは、佐藤 さん       ← ちゃんと展開される
```

上はシングルクォートなので、`` ${name} `` が**文字としてそのまま**表示されます。エラーは出ませんが、画面に `${name}` と出て「なんで変数が出ないの？」と悩むことになります。**`${...}` がそのまま画面に出たら、クォートがバッククォートになっているかを真っ先に確認**してください。

<Together

```js
const name = 'トマト'
const price = 320

console.log(`${name}：${price}円`)
// → トマト：320円
```

1 つの文字列に `` ${name} `` と `` ${price} `` を 2 か所差し込んでいます。`円` のような固定の文字は、そのまま地の文として書けます。

</Together>

## 書き方カタログ：差し込みのいろいろ {#catalog}

`${ }` の中には、変数だけでなく式も書けます。よく使う形を並べます。

```js
const name = '佐藤'
const price = 320

`${name} さん`                        // 変数を差し込む
`合計：${price * 1.1}円`              // 式も書ける（計算結果が入る）
`${name}：${price}円`                 // 複数の差し込み
`在庫：${price > 0 ? 'あり' : 'なし'}` // 三項演算子も入れられる
`1行目
2行目`                                // 改行もそのまま書ける
```

「地の文」と「差し込む値」を、見たままの並びで書けるのが強みです。`+` の連結より読み間違いが減ります。

`` `${name} さん` `` の形は、地の文と値の並びがそのまま目に見えるので、読み間違いが減ります。React で画面に文字を出すときにも多用します。

## うまくいかないとき {#trouble}

- **`${name}` が画面にそのまま出る** … 囲みがシングル/ダブルクォートになっています。バッククォートに直します。
- **バッククォートが打てない** … 日本語キーボードでは `Shift` を押さずに `@` の左のキー、または `半角/全角` の下あたりにあります。見つからなければ「バッククォート 入力 方法」で検索してください。
