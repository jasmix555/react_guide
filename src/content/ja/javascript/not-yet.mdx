</LearnBox>

## このページの使い方 {#how}

JavaScript は歴史が長く、機能がとても多い言語です。ネットの記事や既存のコードには、ここまでで説明していない書き方がたくさん出てきます。そのたびに「これも覚えないと」と身構えると、いつまでも React にたどり着けません。

**このパートで学んだ文法が分かっていれば、React は書けます。** 以下は「見かけても、今は素通りでいい」もののリストです。必要になったら、そのとき調べれば十分です。

## 見かけても、今は飛ばしていいもの {#skip}

| 見かける書き方 | 今は |
|---|---|
| `class` / `this` の込み入った話 | 関数コンポーネントでは使いません。飛ばしてOK |
| `prototype`（プロトタイプ） | 仕組みの深い話。今は不要 |
| `reduce`（複雑な集計） | `map` / `filter` で足りるうちは後回しでOK |
| `function*` / `yield`（ジェネレータ） | 高度な機能。当面出番なし |
| 正規表現 `/.../`（パターン照合） | 必要になった箇所で個別に調べれば十分 |
| ビット演算（`&` や `^` など） | Web の画面作りではほぼ使いません |
| `Symbol` / `Proxy` / `WeakMap` | ライブラリの内部向け。書く側は当面不要 |

<Callout type="note">

「飛ばしていい」は「一生要らない」ではありません。**今の目的（React で画面を作る）に要らない**、という意味です。手を広げるより、まず 13 個を確実に使えるようにするほうが、ずっと早く上達します。

</Callout>

## 逆に「使わない」と決めるもの {#avoid}

こちらは「今は飛ばす」ではなく、**うちでは積極的に避ける**書き方です。見かけたら、新しいコードでは使わないでください。

- **`var`** … `const` / `let` を使います（[const と let](/guide/javascript/const-let) 参照）。
- **`==`（ゆるい比較）** … 予想外の型変換で事故ります。必ず **`===`** を使います。
- **`function` 式の乱用** … アロー関数で揃えます（トップレベルの宣言を除く）。

<Callout type="analogy">

道具箱に古い工具も入っていますが、うちの現場では新しい方（`const` / `===` / アロー）で揃える、という取り決めです。古い工具（`var` / `==`）を見かけても、真似せず新しい方で書きます。

</Callout>

## 書き方カタログ：うちで使う書き方 {#catalog}

このパートで学んだ「使う側」の書き方を、1 か所にまとめます。コンソールにそのまま貼れば、これだけで動きます（`var` や `==` は使いません）。

```js
const price = 100                 // var ではなく const
let count = 0                     // 変わる値だけ let
const double = n => n * 2         // アロー関数
const { name } = { name: '佐藤' } // 分割代入
const next = [...[1, 2], 3]       // スプレッド
console.log(price === 100)        // 比較は === （== は使わない）
console.log(double(count))        // → 0
console.log(name, next)           // → 佐藤 [1, 2, 3]
```

この形に揃えておけば、この先の React のページはすべて同じ書き方で読めます。迷ったら、この一覧に戻ってきてください。

## まとめ {#summary}

- `var` と `==` は避け、`const` / `let` と `===` を使う
