## いちばん簡単な入れ方 {#simple}

まず素直に、公式サイトのインストーラで入れる方法です。

1. ブラウザで [nodejs.org](https://nodejs.org) を開きます。
2. 2 つ並んだボタンのうち、**「LTS」と書かれたほう**をクリックしてインストーラをダウンロードします。
3. ダウンロードしたファイルをダブルクリックし、表示される画面はすべて既定のまま「次へ / Next」で進めてインストールします。
4. **ターミナルを一度閉じて、開き直します。**（ここが重要。閉じないと反映されません。）
5. `node -v` を打って、`v22.x.x` のようにバージョンが出れば成功です。

<Callout type="warn">

「LTS」ではなく「Current（最新版）」を選んでも動きはしますが、実験的な変更が入っていて、ライブラリがまだ対応していないことがあります。**迷わず LTS** を選んでください。

</Callout>

## なぜ LTS なのか {#why-lts}

**LTS（長期サポート版）は、長期間バグ修正が続く安定版**です。仕事で使うコードは「動き続けること」が最優先なので、尖った最新版よりも、枯れて安定した LTS を選びます。React やライブラリ側も LTS を前提に作られているので、トラブルが起きにくいという実利もあります。

## 案件ごとにバージョンを変える — volta / nvm {#volta}

ここは今すぐ必要ではありませんが、知っておくと後で助かる話です。

現場で複数の案件を持つと、**案件 A は Node 18、案件 B は Node 22**、というふうにプロジェクトごとに必要な Node のバージョンが違うことが起きます。公式インストーラで入れた Node は PC に 1 つだけなので、切り替えられません。

これを解決するのが **volta**（や **nvm**）という「Node のバージョン切り替え道具」です。プロジェクトのフォルダに入ると、そのプロジェクトが要求するバージョンへ**自動で切り替わる**のが便利なところです。

<Callout type="note">

**うちの標準：バージョン管理が必要になったら volta。** Windows でも素直に動き、プロジェクトごとの自動切り替えが効きます。ただし React を学び始める今この瞬間は、公式インストーラの LTS 1 本で十分です。案件を掛け持ちし始めたら volta を入れる、で間に合います。

</Callout>

<Deeper title="volta の入れ方（今はやらなくてよい）">

[volta.sh](https://volta.sh) の手順に沿って volta 本体を入れたあと、プロジェクトのフォルダで `volta pin node@22` を実行すると、そのバージョンが `package.json` に記録されます。以降そのフォルダに入ると、volta が自動で Node 22 に合わせてくれます。チームで同じバージョンに揃えられるのが利点です。

</Deeper>

## うまくいかないとき {#trouble}

- **入れたのに `node -v` がまだ通らない** … 9 割はターミナルの閉じ直し忘れです。**すべてのターミナル（と VS Code）を閉じて、開き直して**からもう一度。
- **Windows で「PATH が…」という表示が出た** … 通常はインストーラが自動で設定します。閉じ直しても通らない場合は、PC を再起動すると反映されます。

<SummaryBox>

- [nodejs.org](https://nodejs.org) の **LTS** を入れ、ターミナルを開き直して `node -v` で確認
- LTS は長期サポートの安定版。仕事のコードには尖った最新版より安定を選ぶ
- 案件を掛け持ちして Node のバージョン差が問題になったら volta を導入する

</SummaryBox>
