<LearnBox>

- `node -v` `npm -v` でインストール済みか確認する
- 出力される `v22.11.0` のような文字の読み方
- 「入っていない」ときに出るエラーの見分け方

</LearnBox>

Node.js は、すでに入っている PC もあれば、入っていない PC もあります。まず確認しましょう。**入っていればこのページで確認して次へ進めます。入っていなければ次のページで入れます。**

## ステップ 1：バージョンを表示する {#step-node}

ターミナルに次を打って `Enter` します。

```bash
node -v
```

入っていれば、こう表示されます（数字はあなたの環境で変わります）。

```
v22.11.0
```

この `v22.11.0` は Node.js の**バージョン**です。読み方は左から **メジャー.マイナー.パッチ**。ここでは「メジャーバージョン 22」が一番大事な情報です。**メジャーが 20 以上**なら、このガイドの内容はそのまま動きます。

## ステップ 2：npm も確認する {#step-npm}

続けて npm も確認します。

```bash
npm -v
```

こう出ます（数字は違って構いません）。

```
10.9.0
```

npm は Node.js に付いてくるので、`node -v` が出れば `npm -v` も出るはずです。両方バージョンが表示されたら、Node.js は入っています。**このパートのページ 5 を飛ばして、ページ 6「なぜ Vite なのか」へ進んで構いません。**

## 入っていないときはこう出る {#not-installed}

もし Node.js が入っていないと、バージョンではなく**エラー**が返ってきます。Windows の PowerShell だと、こういう文面です。

```
node : 用語 'node' は、コマンドレット、関数、スクリプト ファイル、または
操作可能なプログラムの名前として認識されません。
```

Mac だとこうです。

```
zsh: command not found: node
```

どちらも意味は同じで、「**node という道具が見つからない＝入っていない**」ということです。この文が出た人は、次のページ 5 で Node.js を入れます。

<Callout type="warn">

`-v` は必ず**半角ハイフン + 小文字の v**です。全角のハイフンや大文字だと別の意味になり、うまく動きません。コピーして貼るのが確実です。

</Callout>

## LTS とは何か {#lts}

Node.js を入れるとき「**LTS**」という言葉を見かけます。**LTS（Long Term Support）＝長期間サポートされる安定版**のことです。最新の実験的な版ではなく、この LTS を選ぶのが定番です。理由は次のページで扱います。

## うまくいかないとき {#trouble}

- **さっき入れたのにまだ「認識されません」と出る** … Node.js を入れた後は、**開いているターミナルを一度閉じて開き直す**必要があります。閉じずに打つと、古い状態のままで見つかりません。
- **バージョンが `v16` など古い** … 動くには動きますが、このガイドは 20 以上を前提にしています。次のページの手順で入れ直すのが安全です。

<SummaryBox>

- `node -v` `npm -v` の両方でバージョンが出れば、Node.js は入っている
- `v22.11.0` の左端の数字（メジャー）が 20 以上なら OK
- 「認識されません / command not found」が出たら、次のページで入れる

</SummaryBox>
