## gsap.to / from / fromTo {#basics}

GSAP の基本は 3 つの命令です。「どの要素を、どういう状態へ」を書きます。

```tsx
// to：今の状態 → 指定した状態へ動かす
gsap.to('.box', { x: 100, opacity: 1, duration: 0.6 })

// from：指定した状態 → 今の状態へ（「出てくる」動き）
gsap.from('.box', { opacity: 0, y: 20, duration: 0.6 })

// fromTo：開始も終了も自分で決める
gsap.fromTo('.box', { opacity: 0 }, { opacity: 1, duration: 0.6 })
```

- 第 1 引数は**対象**（CSS セレクタや要素）。`.box` のように書けます。
- 第 2 引数（`to`）または第 2・第 3 引数（`fromTo`）が**動かす先の状態**。`x` / `y`（移動）、`opacity`（透明度）、`scale`（拡大）、`rotate`（回転）などを指定します。
- `duration` は秒、`ease` は緩急、`stagger` は「少しずつずらす」です。

<JsNote feature="from は「出てくる」動き">

`from` は「**その状態から、今の見た目へ**」動きます。`from({ opacity: 0, y: 20 })` は「透明で少し下 → 定位置」なので、`initial` → `animate`（[Framer Motion](/libraries/framer-motion/motion-basics)）の「フワッと出る」と同じ絵になります。

</JsNote>

## useGSAP の形 {#usegsap}

React では、この命令を **`useGSAP` の中**に書きます。`scope` に「箱」の ref を渡すと、`.card` のようなセレクタが**その箱の中だけ**を指すようになります（他の場所の `.card` を巻き込みません）。後片付けは `useGSAP` が自動でやります。

```tsx
import { useGSAP } from '@gsap/react'
import gsap from 'gsap'
import { useRef } from 'react'

function List() {
  const container = useRef<HTMLUListElement>(null)

  useGSAP(
    () => {
      gsap.from('.card', { opacity: 0, y: 16, stagger: 0.08 })
    },
    { scope: container }, // ← .card はこの箱の中だけ
  )

  return <ul ref={container}>{/* .card を並べる */}</ul>
}
```

```tsx
useGSAP(() => { ... }, { scope: container })
//      └─ ここに gsap の命令を書く     └─ セレクタを限定する箱
```

CSS Modules を使っているので、実際のクラス名は `styles.card`（ハッシュ付き）です。セレクタも `` `.${styles.card}` `` と書きます。次の完成コードで確かめます。

## 完成コード：少しずつ出るカード {#full}

商品カードを、マウント時に**少しずつフワッと**出します。読みどころは、`useGSAP` の中に `gsap.timeline().from(...)` を書くこと、`scope` で箱を渡すこと、`matchMedia` で配慮することの 3 つです。

```tsx title="src/demos/GsapStagger/GsapStagger.tsx（全文）"
import { useGSAP } from '@gsap/react'
import gsap from 'gsap'
import { useRef } from 'react'

import products from '@/data/products.json'

import styles from './GsapStagger.module.scss'

export function GsapStagger() {
  const container = useRef<HTMLUListElement>(null)
  const anim = useRef<gsap.core.Timeline | null>(null)
  const items = products.slice(0, 4)

  useGSAP(
    () => {
      const mm = gsap.matchMedia()
      // 「動きを減らす」設定でなければ animate する
      mm.add('(prefers-reduced-motion: no-preference)', () => {
        anim.current = gsap.timeline().from(`.${styles.card}`, {
          opacity: 0,
          y: 16,
          duration: 0.5,
          stagger: 0.08,
          ease: 'power2.out',
        })
      })
    },
    { scope: container },
  )

  return (
    <div className={styles.wrap}>
      <ul className={styles.grid} ref={container}>
        {items.map((p) => (
          <li key={p.id} className={styles.card}>
            <span className={styles.name}>{p.name}</span>
            <span className={styles.price}>{p.price.toLocaleString()}円</span>
          </li>
        ))}
      </ul>
      <button type="button" className={styles.replay} onClick={() => anim.current?.restart()}>
        もう一度
      </button>
    </div>
  )
}
```

「もう一度」は、作ったアニメーションを覚えておいて（`anim` の ref）、`restart()` で最初から再生しています。`gsap.timeline()` は次のページで詳しく扱いますが、ここでは「`from` を 1 つ入れた入れ物」だと思ってください。

## reduced-motion に配慮する {#reduce}

`gsap.matchMedia()` は「今この条件に合っているときだけ、この動きを登録する」仕組みです。`(prefers-reduced-motion: no-preference)`＝「動きを減らしていない人」のときだけアニメーションを登録するので、**減らす設定の人には最初から静止**した状態で出ます（情報は消えません）。設定を切り替えると、`matchMedia` が自動で登録・解除をやり直します。

<Callout type="note" title="Framer Motion の useReducedMotion と同じ配慮">

[Framer Motion では `useReducedMotion`](/libraries/framer-motion/reduced-motion) で同じことをしました。GSAP では `gsap.matchMedia()` が担当です。道具は違っても、**動きだけ消し、情報は残す**という原則は同じです。

</Callout>

## うまくいかないとき {#trouble}

- **動かない** … `useGSAP` の中に書いているか、`scope` の ref を対象の親に付けているか確認します。
- **他の場所まで動く** … `scope` を渡していないと、`.card` がページ中の同名クラスを巻き込みます。`{ scope: container }` を付けます。
- **開発中に二重に動く** … `useGSAP` を使えば正しく処理されます。生の `useEffect` にしていないか確認します。
