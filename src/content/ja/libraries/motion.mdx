## アニメーションを React らしく付ける {#why}

LP 制作では、ふわっと出す・スクロールで動かす、といったアニメーションをよく使ってきたと思います。CSS の `transition` や `@keyframes` でも書けますが、「**表示された瞬間・消える瞬間**」や「一覧の要素が順番に出てくる」といった、React の表示の切り替わりに合わせた動きは、専用の部品があると格段にラクになります。

うちで使うのが **`motion`** です。「この要素を、こう動かす」を宣言的に書けます。

<Callout type="analogy">

CSS のアニメーションが「手でストップウォッチを見ながら動かす」なら、`motion` は「開始と終了の状態を伝えると、間をなめらかにつないでくれる」係です。細かいタイミング計算を任せられます。

</Callout>

## 入れる {#install}

画面の動作に関わるので `dependencies`（`-D` なし）で入れます。

```bash
npm install motion
```

`package.json` の `dependencies` に `motion` が増えます。型は本体に同梱されています。

## 使い方は Framer Motion のパートで {#later}

`motion` の使い方は、コンポーネントや state（画面の状態）を理解してからのほうが腑に落ちます。「ボタンを押したら開く」「一覧が順に現れる」といった動きは、React の状態と結びついているからです。なので **ここでは入れるところまで**にして、実際の書き方は[Framer Motion のパート](/libraries/framer-motion/goal)で詳しくやります。

ここでは「アニメーションを付けたくなったら `motion`」とだけ覚えておけば十分です。
