<PartIntro>

**Swiper**（スワイパー）は、スライダー・カルーセルの定番ライブラリです。LP でよく見る「ヒーローのスライドショー」「商品を横に流すカルーセル」「お客様の声のスライダー」などを、タッチ操作・レスポンシブ対応込みで手早く作れます。

指でのスワイプ、マウスのドラッグ、矢印やドット、自動再生、画面幅ごとの表示枚数の切り替え——スライダーに欲しいものが一通りそろっていて、無料で使えます。React からは公式の `swiper/react` で扱えます。

</PartIntro>

## Swiper は何が得意か {#why}

スライダーを自前で作ると、地味に大変です。スワイプの指の動き、慣性、端の処理、矢印、ドット、自動再生、レスポンシブ……と考えることが多く、バグも出やすい部分です。**Swiper はこれを全部用意してくれます。**

- **タッチ・ドラッグ操作** … スマホのスワイプも、PC のドラッグも最初から効く。
- **レスポンシブ** … `breakpoints` で「この幅からは 3 枚」のように表示枚数を変えられる。
- **機能はモジュールで** … 矢印（Navigation）・ドット（Pagination）・自動再生（Autoplay）など、必要なものだけ足す。
- **アクセシビリティ** … A11y モジュールで、スクリーンリーダー向けの情報も付く。

「横に流す」「スライドショー」が要るときの第一候補です。逆に、単純な 2〜3 枚の切り替えなら、[レシピのカルーセル](/recipes/carousel)のように自前でも作れます。作るものの規模で選びます。

## このパートの進み方 {#roadmap}

1. **入れる** — `swiper` を入れて、**CSS の読み込み**を忘れない。
2. **基本** — `Swiper` と `SwiperSlide` でいちばん小さいスライダーを作る。
3. **モジュール** — 矢印・ドット・自動再生を足す。
4. **商品カルーセル** — `breakpoints` でレスポンシブにして仕上げる。
