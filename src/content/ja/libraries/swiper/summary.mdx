## このパートの総復習 {#recap}

Swiper で、タッチ操作つきのスライダー・カルーセルを組めるようになりました。要点を並べます。

- **セットアップ** … `npm install swiper` の後、**`import 'swiper/css'` を忘れない**（崩れて見える原因の第 1 位）。
- **基本** … 外側 `Swiper` ＋ 中に `SwiperSlide`。`slidesPerView` / `spaceBetween` / `loop` が基本設定。一覧は `map` ＋ `key`。
- **モジュール** … `swiper/modules` から読み込み `modules={[...]}` に渡す＋ CSS も足す。Navigation・Pagination・Autoplay・A11y。
- **レスポンシブ** … `breakpoints`（min-width）で表示枚数を切り替える。
- **配慮** … 自動再生は `useReducedMotion` で、減らす設定のとき止める。

## 次に読むと良いもの {#next}

これで **Swiper** は一通りです。CSS の読み込みから、基本、モジュール、レスポンシブまで、実務のカルーセルを自分で組めるようになりました。

同じ **ライブラリ編** には、**Tailwind**（ユーティリティ CSS）、**React Icons**（アイコン）、**Lenis**（スムーススクロール、GSAP と相性◎）などを、順次追加していきます。「まず自前で作れないか」を考えるなら、**[レシピのカルーセル](/recipes/carousel)** との読み比べも力になります。

<SummaryBox>

- `import 'swiper/css'` を忘れない／`Swiper` ＋ `SwiperSlide`／`modules` で機能を足す
- `breakpoints`（min-width）でレスポンシブ、自動再生は reduced-motion に配慮
- 単純な切り替えは自前（レシピ）、本格的なスライダーは Swiper

</SummaryBox>
