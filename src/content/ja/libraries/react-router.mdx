## ルーティングとは「画面の切り替え」 {#why}

LP は 1 枚のページで完結することが多いですが、アプリになると「一覧 → 詳細 → カート」のように**複数の画面**を行き来します。このとき、URL（`/products`、`/cart` など）に応じて**表示する画面を切り替える**仕組みを **ルーティング** と呼びます。

React 自体にはルーティング機能が無いので、部品で足します。うちで使うのが **`react-router`** です（実は、あなたが今読んでいるこの学習サイトも react-router で画面を切り替えています）。

<Callout type="analogy">

建物の受付と案内図のようなものです。「`/cart` に行きたい」と言われたら、カートの部屋へ案内する。ルーティングは、URL という住所を見て、どの画面を出すかを決める案内係です。

</Callout>

## 入れる {#install}

画面の動作に必要なので `dependencies`（`-D` なし）で入れます。パッケージ名は `react-router-dom` です。

```bash
npm install react-router-dom
```

`package.json` の `dependencies` に `react-router-dom` が増えます。型は本体に同梱されているので、`@types/*` は要りません。

<Callout type="note">

パッケージ名は `react-router-dom`（末尾に `-dom`）です。Web 向けの部品がこちらにまとまっています。名前が長いので、入れるときに間違えやすい点だけ注意してください。

</Callout>

## 設定そのものは Part 7 {#later}

ルーティングは「入れれば動く」ものではなく、「どの URL でどの画面を出すか」を**設定するコード**を書いて初めて機能します。その設定は React の構造（コンポーネント）を理解してからのほうが分かりやすいので、**このページは入れるところまで**。書き方は [Part 7・ルーティング](/guide/routing/setup-router)でまるごと扱っています。

ここでは「画面を切り替えたくなったら `react-router` を使う」「パッケージ名は `react-router-dom`」の 2 つを覚えておけば十分です。
