## つまみは自作しない {#native-first}

スライダーを「`div` を並べてドラッグ位置を計算して……」と自作すると、地獄です。ブラウザには**最初からスライダーが入っています**。`<input type="range">` と書くだけで、ドラッグもキーボード操作（矢印キー）も付いてきます。

```tsx title="いちばん短いスライダー"
<input type="range" min={0} max={100} />
```

必要なのは「いまいくつか」を受け取って使うこと。そこだけ React でやります。

## 値を state に読み取る {#read-value}

スライダーの値を使うには、`useState` に読み取ります。ポイントは 1 つだけ、**`e.target.value` は文字列で来る**ことです。

```tsx
const [max, setMax] = useState(5000)

<input
  type="range"
  min={0}
  max={10000}
  step={500}
  value={max}
  onChange={(e) => setMax(Number(e.target.value))}
/>
```

- **`min` / `max`** … 動かせる範囲。ここでは `0`〜`10000`。
- **`step`** … 刻み幅。`500` なら 500 ずつ動きます。
- **`value={max}`** … いまの値（state）をスライダーに反映。
- **`onChange`** … 動かすたびに呼ばれる。`e.target.value` は `"5000"` のような**文字列**なので、`Number(...)` で数値に直してから `setMax` に渡します。

<JsNote feature="e.target.value は文字列で来る">

`<input>` の値は、`type="range"` でも `type="number"` でも、**常に文字列**として渡されます。`Number(e.target.value)` で数値にしないと、`+` が足し算ではなく文字列連結になり、計算が狂います。

</JsNote>

## 再利用できる形にする {#reusable}

毎回この `<input>` を書くのは面倒なので、ラベルと値表示をまとめた小さな部品にします。`src/components/RangeSlider/RangeSlider.tsx` を新規作成してください。

```tsx title="src/components/RangeSlider/RangeSlider.tsx（新規作成・全文）"
interface RangeSliderProps {
  label: string
  min: number
  max: number
  step?: number
  value: number
  onChange: (value: number) => void
  format?: (value: number) => string
}

export function RangeSlider({
  label,
  min,
  max,
  step = 1,
  value,
  onChange,
  format,
}: RangeSliderProps) {
  return (
    <label>
      <span>
        {label}
        <span>{format ? format(value) : value}</span>
      </span>
      <input
        type="range"
        min={min}
        max={max}
        step={step}
        value={value}
        onChange={(e) => onChange(Number(e.target.value))}
      />
    </label>
  )
}
```

使う側は、値の state と「どう表示するか（`format`）」だけ渡します。

```tsx title="使う側"
const [max, setMax] = useState(5000)

<RangeSlider
  label="価格の上限"
  min={0}
  max={10000}
  step={500}
  value={max}
  onChange={setMax}
  format={(v) => `${v.toLocaleString()} 円以下`}
/>
```

## 色を着ける {#styling}

つまみやバーの色は、CSS 一行で変えられます。`::-webkit-slider-thumb` のようなブラウザごとの指定を書かなくても、`accent-color` が効きます。

```scss title="RangeSlider.module.scss"
.range {
  width: 100%;
  accent-color: var(--c-accent);
}
```

## うまくいかないとき {#trouble}

- **数字がおかしい・連結される** … `Number(e.target.value)` を忘れています。値は文字列で来ます。
- **つまみが動かない** … `value` を渡しているのに `onChange` が無いと固定されます。両方セットで書きます。

## まとめ {#summary}

<SummaryBox>

- スライダーは自作せず `<input type="range">`。ドラッグもキーボードも付いてくる
- `value` と `onChange` をセットで書き、`e.target.value` は `Number(...)` で数値に直す
- 色は `accent-color` 一行。ブラウザごとの thumb 指定は要らない
