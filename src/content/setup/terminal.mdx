React のプロジェクト作成も、起動も、ライブラリの追加も、すべて**ターミナル**に文字を打って行います。LP 制作ではほとんど使わなかったので身構えるかもしれませんが、やることは「決まった文字を打って Enter」だけです。

## ターミナルとは {#what}

ターミナルは、**マウスでクリックする代わりに、文字で PC に命令する画面**です。「このフォルダにプロジェクトを作れ」「サーバーを起動しろ」といった命令を、1 行ずつ打って実行します。

## Windows で開く {#windows}

Windows には黒い画面が何種類かありますが、**VS Code の統合ターミナルを使うのが一番ラク**です。エディタとターミナルが同じ画面に並ぶので、行き来が要りません。まずはこれを使いましょう（VS Code の入れ方は後のページで扱います）。

VS Code を開いた状態で、上部メニューの **ターミナル → 新しいターミナル**（または `Ctrl` + `@` ＝ Shift を押さずに `@` キー）を選びます。画面の下半分にターミナルが開きます。

VS Code を使わずに単体で開くなら、スタートメニューで「**PowerShell**」と検索して起動します。

<Callout type="note">

Windows には「コマンドプロンプト（cmd）」と「PowerShell」があります。このガイドは **PowerShell** で統一します。見分け方は、行頭が `PS C:\Users\...>` のように **`PS` で始まっていれば PowerShell** です。

</Callout>

## Mac で開く {#mac}

`command` + `Space` で Spotlight を開き、「ターミナル」と打って `Enter`。あるいは Windows と同じく、VS Code の統合ターミナルを使っても構いません。

## 今どこにいるか・どこへ移動するか {#navigate}

ターミナルは常に「今このフォルダにいる」という状態を持っています。プロジェクトを作る前に、これを意識できると迷いません。

いる場所を表示するには、次を打って `Enter` します。

```bash
# Windows(PowerShell) も Mac も、これで現在地が出ます
pwd
```

`C:\Users\yourname` のような、今いるフォルダのパスが表示されます。別のフォルダへ移動するには `cd`（change directory）を使います。

```bash
# デスクトップへ移動する例
cd Desktop
```

<Callout type="analogy">

`cd` は、エクスプローラーや Finder でフォルダをダブルクリックして中に入るのと同じことを、文字でやっているだけです。

</Callout>

## うまくいかないとき {#trouble}

- **`@` を押しても統合ターミナルが開かない** … キーボードによって記号の位置が違います。メニューの「ターミラル → 新しいターミナル」から開けば確実です。
- **`cd` で「そのようなパスはありません」と出る** … いる場所（`pwd`）と、移動先フォルダの名前（大文字小文字も）を確認してください。日本語や空白を含むフォルダ名は、後で面倒になりがちなので避けるのが無難です。

<SummaryBox>

- ターミナルは「文字で PC に命令する画面」。やることは決まった文字を打って Enter
- Windows は VS Code の統合ターミナル（＝ PowerShell）が一番ラク
- `pwd` で現在地、`cd` で移動。プロジェクトは英数字のフォルダ名の場所で作る

</SummaryBox>
