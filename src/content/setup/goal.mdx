<Callout type="note" title="もう環境が整っている人へ（スキップ可）">

このパートは Node.js や `npm` を**まだ入れていない人**のために、一番丁寧に書いています。すでに道具がそろっている人は、下から入って構いません。

- **Node / npm（または pnpm）はもう入っている** → [`npm create vite` から始める](/guide/setup/create-vite)
- **環境構築は自分でできる（Vite プロジェクトを作れる）** → [Part 2「React の前に必要な JavaScript」へ](/guide/javascript/const-let)（JS も分かる人は [Part 3「はじめての React」](/guide/components/goal) へ）

</Callout>

React の勉強でつまずく人のほとんどは、`useState` でも `props` でもなく、**その手前**でつまずきます。「動くプロジェクトを自分の PC に立ち上げる」ところです。ここさえ越えれば、あとは坂を下るだけです。だからこのパートを一番丁寧に書きました。

## 終わったときに手元にあるもの {#goal}

このパートを最後までやると、あなたの PC には次の 3 つがそろっています。

1. **動いている React プロジェクト** — ブラウザの `http://localhost:5173` を開くと、あなたが作ったアプリが表示されます。
2. **中身が分かっている状態** — `main.tsx` って何、`vite.config.ts` って何、という「知らないファイルが怖い」状態を抜けています。
3. **白紙のキャンバス** — Vite が最初に置いていくサンプルを全部消して、次のパートから自分のコードを書き始められる状態。

まず途中の景色を見せます。`npm run dev` を実行してブラウザを開くと、最初はこういう画面が出ます（Vite が用意したサンプルページです）。

<Callout type="note">

紫色のロゴと「Get started」「Count is 0」というボタンが並んだページが出ます。ボタンを押すと数字が増えます。これは **React がちゃんと動いている証拠** であって、あなたのアプリではありません。このパートの後半で、これを全部消して白紙にします。

</Callout>

## なぜ環境構築が最重要なのか {#why}

LP を作るときのことを思い出してください。`index.html` を作って、ブラウザにドラッグすれば表示されました。ビルドも、インストールも要りませんでした。

React は違います。あなたが書く `.tsx` はブラウザがそのままでは読めません。**変換（ビルド）する道具**を先に用意しないと、1 文字も表示できません。この「道具を用意する」作業が環境構築です。ここが動かないと、この先のページは全部机上の空論になります。

<Callout type="analogy">

包丁を持っていない人に包丁の握り方を教えても意味がないのと同じです。まず包丁（動くプロジェクト）を手に入れる。それがこのパートです。

</Callout>

## このパートの進み方 {#roadmap}

21 ページを、大きく 4 つのかたまりに分けています。急がず、上から順にやってください。

1. **道具の確認（ページ 2〜5）** — Node.js とは何か、ターミナルの開き方、入っているかの確認、入っていない場合の入れ方。
2. **プロジェクトを作る（ページ 6〜15）** — なぜ Vite なのか、`npm create vite` の実行、聞かれる選択肢の全説明、`npm install` と `npm run dev`。
3. **中身を理解する（ページ 16〜19）** — 生成されたファイルを 1 つずつ読み、初めての編集で HMR を体感し、白紙にし、エディタを整える。
4. **転ばぬ先の杖（ページ 20〜21）** — Windows で必ず出るエラーの対処と、まとめ・練習問題。
