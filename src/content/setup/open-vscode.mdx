<LearnBox>

- できたプロジェクトフォルダを VS Code で開く
- 左のエクスプローラ・中央のエディタ・下のターミナルの役割
- ターミナルが「プロジェクトの中」にいる状態にする

</LearnBox>

プロジェクトフォルダはできました。次は、それを**エディタで開いて中身を見られる状態**にします。エディタは **VS Code** を使います。無料で、React 開発の定番です。

## VS Code を入れる {#install}

まだ入っていなければ、[code.visualstudio.com](https://code.visualstudio.com) からダウンロードしてインストールします。画面はすべて既定のまま進めて構いません。

## フォルダを開く {#open}

VS Code を起動したら、上部メニューの **ファイル → フォルダーを開く**（File → Open Folder）を選び、さっき作った `my-shop` フォルダを選んで開きます。

<Callout type="note">

「ファイルを開く」ではなく「**フォルダーを開く**」です。React のプロジェクトはたくさんのファイルの集まりなので、1 ファイルではなく**フォルダごと**開くのが基本です。「作成者を信頼しますか？」と聞かれたら「信頼する」を選びます（自分で作ったフォルダなので安全です）。

</Callout>

## 画面の見方 {#layout}

VS Code の画面は、大きく 3 つの領域に分かれています。

- **左：エクスプローラ** … プロジェクトのファイル一覧。`src` や `package.json` が並んで見えます。
- **中央：エディタ** … ファイルをクリックすると、ここに中身が開いて編集できます。
- **下：ターミナル** … コマンドを打つ場所（前のページで触れた統合ターミナル）。

<Callout type="analogy">

左のエクスプローラは、エクスプローラ／Finder のフォルダツリーと同じものです。VS Code の中にファイル管理と、エディタと、ターミナルが全部入っている、と考えてください。

</Callout>

## ターミナルをプロジェクトの中で開く {#terminal-here}

これが地味に重要です。上部メニューの **ターミナル → 新しいターミナル** を開くと、VS Code は**今開いているフォルダの中**でターミナルを開いてくれます。行頭のパスが `...\my-shop>` のように、プロジェクト名で終わっていれば正解です。

この状態だと、次のページの `npm install` を「正しい場所」で実行できます。単体の PowerShell で開くと別の場所にいることが多く、`cd my-shop` で自分で入る必要があるので、**VS Code の統合ターミナルが確実でラク**です。

## うまくいかないとき {#trouble}

- **ターミナルのパスが `my-shop` で終わっていない** … 別のフォルダを開いています。「フォルダーを開く」で `my-shop` を開き直してください。
- **`code` というコマンドをターミナルで使いたいのに動かない** … VS Code のコマンドパレット（`Ctrl` + `Shift` + `P`）で「shell コマンド」を検索し、「PATH に code コマンドをインストール」を実行すると使えるようになります（任意）。
