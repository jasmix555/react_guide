<LearnBox>

- `npm run dev` で開発サーバを起動する
- 出力に出る `localhost` とポート番号の意味
- サーバの止め方（`Ctrl` + `C`）と、再起動が必要な場面

</LearnBox>

材料はそろいました。いよいよ**起動して、ブラウザに画面を出します**。このページのゴールは、`http://localhost:5173` を開くと Vite のサンプルページが表示されることです。

## ステップ 1：起動する {#step-run}

統合ターミナルで、次を打ちます。

```bash
npm run dev
```

一瞬で、こういう出力が出ます。

```
  VITE v8.2.0  ready in 431 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

`ready`（準備できた）と、`Local: http://localhost:5173/` という**URL** が出れば起動成功です。

## localhost とポートとは {#localhost}

`http://localhost:5173` の意味を分解します。

- **`localhost`** … 「**この PC 自身**」を指す住所です。Vite が、あなたの PC の中に小さな Web サーバを立ち上げ、そこにアプリを配信しています。ネットに公開されているわけではなく、あなたの PC の中だけで見えている状態です。
- **`5173`** … **ポート番号**。同じ PC の中で複数のサーバを区別するための「部屋番号」です。Vite は既定で 5173 番の部屋を使います。

<Callout type="analogy">

`localhost` が「自分のビル」、ポート番号が「部屋番号」です。5173 号室で Vite のサーバが営業中、というイメージです。

</Callout>

## ステップ 2：ブラウザで開く {#open}

ターミナルの `http://localhost:5173/` を、`Ctrl` を押しながらクリックするとブラウザで開きます（手で打っても構いません）。紫のロゴと「Get started」「Count is 0」のサンプルページが出れば、**React が動いています**。

## 止め方と、点けっぱなしの意味 {#stop}

開発中は、このサーバを**点けっぱなし**にします。点いている間だけ `localhost` が見えます。

止めるときは、`npm run dev` を実行しているターミナルで **`Ctrl` + `C`** を押します。プロンプトが戻れば停止です。止めた瞬間に `localhost:5173` は開けなくなります（サーバが営業終了したため）。もう一度見たくなったら、また `npm run dev` で点けます。

<Callout type="warn">

サーバが動いている間、そのターミナルは「占有」されて他のコマンドを打てません。ライブラリを追加するなど別のコマンドを打ちたいときは、**もう 1 つ新しいターミナルを開く**か、一度 `Ctrl` + `C` で止めてから打ちます。

</Callout>

## 再起動が必要な場面 {#restart}

ほとんどの編集は、保存すれば自動で画面に反映されます（次のページで体感します）。ただし、次のような**設定まわりを変えたときは、`Ctrl` + `C` で止めて `npm run dev` で入れ直す**必要があります。

- `vite.config.ts` を編集したとき
- ライブラリを新しく `npm install` したとき
- `.env`（環境変数のファイル）を変えたとき

## もう1つ起動して、ポートの変化を見る {#second-server}

ポートの「部屋番号」を実感してみましょう。**サーバを止めずに**、もう 1 つ新しいターミナルを開いて、そこでもう一度起動します。

```bash
npm run dev
```

すると、5173 号室は使用中なので、Vite はこう言って別の部屋を使います。

```
Port 5173 is in use, trying another one...

  ➜  Local:   http://localhost:5174/
```

`5174` に変わりました。「ポートが使用中」はエラーではなく、Vite が気を利かせて隣の部屋を取っただけです。確認できたら、片方のターミナルで `Ctrl` + `C` を押して、余分なサーバは止めておきましょう。

## うまくいかないとき {#trouble}

- **ブラウザが真っ白** … ターミナルに赤いエラーが出ていないか確認します。多くは書いたコードの文法ミスで、エラーにファイル名と行が出ています。
- **`localhost` が開けない** … サーバを `Ctrl` + `C` で止めたままになっていないか、ポート番号（5173 か 5174 か）が合っているかを確認します。

<SummaryBox>

- `npm run dev` で開発サーバが起動し、`http://localhost:5173` に画面が出る
- `localhost`＝この PC 自身、ポート番号＝サーバを区別する部屋番号
- 止めるのは `Ctrl` + `C`。`vite.config` やライブラリを変えたら再起動する

</SummaryBox>
