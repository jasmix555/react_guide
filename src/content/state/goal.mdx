押すたびに **画面の表示そのものが変わって**います。これが state です。「今お気に入りかどうか」という値を state で持ち、それを更新すると、React が**自動で画面を描き直して**くれます。前のパートまでの「表示するだけ」から、「**動く**」へ進みます。

このボタンの**コードは、このパートの各ページで全文を書きながら**学びます（このページは完成イメージの紹介です）。まずは「押すと変わる」感覚だけ持って進んでください。

## state はなぜ React の核心なのか {#why}

React を学ぶうえで、`useState` は**避けて通れない中心**です。なぜなら、アプリの「動き」はほぼすべて state でできているからです。

- カートの個数が増える → 個数を state で持つ
- モーダルが開く・閉じる → 開いているかを state で持つ
- 検索して絞り込む → 検索語を state で持つ
- お気に入りを切り替える → お気に入りかを state で持つ

**「画面が変わる」ものの裏には、必ず state がある**——そう考えて差し支えありません。だからこのパートは、ゆっくり・手を動かしながら進めてください。分からないところは、デモを実際に触って、コードと見比べるのが一番の近道です。

## このパートの進み方 {#roadmap}

上から順に、state を少しずつ深めていきます。

1. **state とは何か** — なぜ「ただの変数」ではダメなのか（ここが肝）。
2. **useState の基本** — 値を持って、更新して、画面を描き直す。
3. **イベントで state を変える** — クリックで切り替える。
4. **オブジェクトの state** — 元を壊さず更新する（Part 2 の参照とコピー）。
5. **配列の state** — 追加・削除・並び替え。
6. **前の値から更新する** — `setCount(c => c + 1)` の意味。
7. **useEffect** — 表示のあとに動く「副作用」。

各ページに**ライブデモ**と**練習**を用意しています。読むだけでなく、必ず自分で書いて動かしてみてください。
