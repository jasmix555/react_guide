## 商品ごとにページは作らない {#why}

商品が 12 個あるからといって、詳細ページを 12 ファイル作るのは無理があります。作るのは**テンプレ 1 つ**。URL の一部（商品の id）だけを変数にして、「その id の商品」を表示します。

- `/product/p01` → p01 の詳細
- `/product/p05` → p05 の詳細

どちらも**同じ `ProductDetailPage`** が担当し、URL の id 部分だけが違います。

## :id でパラメータを受ける {#param}

ルート登録で、変数にしたい部分を **`:名前`** で書きます。

```tsx
{ path: '/product/:id', element: <ProductDetailPage /> }
//                ↑
//                └─ : で始まる部分は「変数」。/product/p01 でも /product/p05 でも一致する
```

`:id` は「ここは何か 1 つの値が入る」という意味です。`/product/p01` でも `/product/xyz` でも、この 1 つのルートに一致します。

## useParams で取り出す {#useparams}

URL に入った id は、`useParams` で取り出します。ルート定義の `:id` と**同じ名前**で受け取ります。

```tsx
import { useParams } from 'react-router-dom'

function ProductDetailPage() {
  const { id } = useParams()
  // /product/p01 を開いていれば、id は 'p01'
}
```

```tsx
const { id } = useParams()
//      ↑            ↑
//      │            └─ URL の :id の部分を取り出す
//      └─ ルート定義の :id と同じ名前で受け取る
```

## 商品を探して表示する {#find}

id が分かれば、その商品を `products` から `find` で探します。ここで大事なのが、**見つからない場合**（存在しない id を打たれたなど）の扱いです。

```tsx title="src/pages/ProductDetailPage.tsx（全文）"
import { useParams } from 'react-router-dom'

import products from '../data/products.json'

export function ProductDetailPage() {
  const { id } = useParams()
  const product = products.find((p) => p.id === id)

  if (!product) {
    return <p>商品が見つかりませんでした。</p>
  }

  return (
    <article>
      <h1>{product.name}</h1>
      <p>{product.price.toLocaleString()}円</p>
      <p>カテゴリ：{product.category}</p>
    </article>
  )
}
```

`if (!product) return ...` で、無いときは早めに切り上げます。この 1 行があると、`product.name` を安全に書けます（[union の narrowing](/guide/typescript/union-literal) と同じ考え方です）。

<JsNote feature="useParams の値は string | undefined">

`useParams` で取り出した `id` は、`string` または `undefined` です（URL にその部分が無いこともあるため）。`find` の結果も「見つかった商品 または `undefined`」。だから `if (!product)` のチェックが要ります。省くと `product.name` で「`product` は `undefined` かもしれない」と型に怒られます。

</JsNote>

## わざと壊す：見つからない場合を扱わない {#break}

`if (!product)` を消してみます。

```tsx title="わざと壊す：チェックを消す"
const product = products.find((p) => p.id === id)
return <h1>{product.name}</h1> // ← product は undefined かもしれない
```

`product.name` に赤い波線が付き、こう出ます。

```
'product' is possibly 'undefined'.
```

「`product` は `undefined` かもしれません」。存在しない id が来たら `find` は `undefined` を返すからです。`if (!product) return ...` を戻せば、その先では「見つかった商品」に絞られ、安全に `product.name` が書けます。

## よくある間違い {#mistakes}

## うまくいかないとき {#trouble}

- **`useParams` の名前が合わない** … ルートの `:id` と、`const { id }` の名前を一致させます。`:productId` なら `const { productId }`。
- **`'product' is possibly 'undefined'`** … `find` の結果を `if (!product)` でチェックしてから使います。
