## なぜルーティングが要るのか {#why}

LP は 1 枚の `index.html` で完結していました。別ページが要れば、`about.html` のように**ファイルを分けて**いました。React の SPA（Single Page Application）は違います。**HTML は 1 枚のまま**、JavaScript が中身を書き換えて「別ページに見せる」のです。

このとき困るのが、次のようなことです。

- 「商品詳細ページ」に**直接の URL**を持たせたい（リンクを共有したい）。
- ブラウザの**戻る・進む**を効かせたい。
- 「今どのページか」で**表示を切り替えたい**。

これを手作業でやると大変です。**react-router** は、「URL とその URL で出す画面」を対応づけてくれる道具です。URL が変われば画面が変わり、リンクを踏んでもリロードは起きません。

## このパートの進み方 {#roadmap}

1. **ルーターを設定する** — 「この URL では、この画面」を登録する。
2. **Link で移動する** — `<a>` の代わりに `<Link>`（リロードしない）。
3. **URL パラメータ** — `/product/:id` の `:id` で、商品ごとの詳細ページ。
4. **共通レイアウト** — 全ページ共通のナビを、`<Outlet>` で 1 か所に。
5. **プログラムで移動** — ボタンなどから `useNavigate` で移動する。
6. **通し課題** — 一覧 → 詳細 → お気に入りの 3 ページを組む。

各ページに**コード全文**と練習を用意しています。`my-shop` で実際に URL を切り替えながら進めてください。
