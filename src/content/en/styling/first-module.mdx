## First, install sass {#install}

Browsers can't read SCSS directly, so you need `sass` to convert it to CSS. If you haven't installed it yet, run the following in `my-shop` (for details, see [Installing sass](/libraries/sass)).

```bash
npm install -D sass
```

Vite recognizes `.scss` automatically once `sass` is installed. No config file needed.

## Create a .module.scss for the component {#create}

Create a style file just for `ProductCard`. The rule is that the file name must end in **`.module.scss`**. Create a new file at `src/components/ProductCard/ProductCard.module.scss`.

```scss title="src/components/ProductCard/ProductCard.module.scss (new file)"
.card {
  border: 1px solid #e5e7eb;
  border-radius: 12px;
  overflow: hidden;
  background: #fff;
}

.body {
  padding: 12px;
}

.name {
  margin: 0;
  font-weight: 600;
}

.price {
  font-weight: 700;
}
```

(We'll group the colors into **design tokens** on a later page. For now we'll go with literal values.)

## Import it and apply it {#apply}

Load this style from `ProductCard.tsx` and assign it to `className`. Let's break down the import line.

```tsx
import styles from './ProductCard.module.scss'
//     ↑                ↑
//     │                └─ reads the .module.scss in the same folder
//     └─ receives an "object" containing the class names (styles.card, etc.)
```

`styles` is an object that holds the class names inside the `.module.scss`. When you write `styles.card`, it's converted at build time into the uniquely scoped class name (like `ProductCard_card_a1b2c`). To apply it, use **curly braces**.

```tsx
<article className={styles.card}>
//                  ↑
//                  └─ styles.card is the unique name. Pass it with curly braces, not as the string "card"
```

## Apply it to all of ProductCard {#full}

Here's the full `ProductCard.tsx` with a `className` added to each element.

```tsx title="src/components/ProductCard/ProductCard.tsx (full)"
import styles from './ProductCard.module.scss'

interface ProductCardProps {
  name: string
  price: number
  imageUrl: string
}

export function ProductCard({ name, price, imageUrl }: ProductCardProps) {
  return (
    <article className={styles.card}>
      <img src={imageUrl} alt={name} width="100%" />
      <div className={styles.body}>
        <h3 className={styles.name}>{name}</h3>
        <p className={styles.price}>{price.toLocaleString()} yen</p>
      </div>
    </article>
  )
}
```

Once you save, the plain row becomes "a card with a border and spacing." It's still modest, but the **mechanism for applying styles** is now complete. From here it's just a matter of adding more to this `.module.scss`.

## When things don't work {#trouble}

- **`styles.card` is `undefined`** … Check that the file name ends in `.module.scss` and that the class name is spelled correctly.
- **The style doesn't apply** … Check that it's `className={styles.card}` (curly braces) and not `className="styles.card"` (a string).
- **`Preprocessor dependency "sass" not found`** … You forgot to install `sass`. Run `npm install -D sass`.
