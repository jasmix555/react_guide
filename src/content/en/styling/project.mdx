## What we're building {#goal}

The goal is that card list you saw at the very start of Part 5. It has images, categories, prices, favorites, and a sold-out indicator, and it wraps according to the screen width. We'll assemble everything from the pages so far into actual files.

## Folder structure {#tree}

Set `my-shop` up in this shape. Gather the color tokens into a single file and load it just once in `main.tsx`.

```
my-shop/src/
├─ main.tsx                       ← imports styles/tokens.scss
├─ App.tsx                        ← the list (grid)
├─ App.module.scss                ← the list layout
├─ styles/
│  └─ tokens.scss                 ← design tokens (--c-*)
├─ components/ProductCard/
│  ├─ ProductCard.tsx
│  └─ ProductCard.module.scss
└─ data/products.json
```

## 1. Tokens in one file {#tokens}

## 3. ProductCard.tsx (full source) {#card-tsx}

Conditional classes with `clsx`, favorites with `useState`, and sold-out via conditional rendering.

```tsx title="src/components/ProductCard/ProductCard.tsx (full source)"
import clsx from 'clsx'
import { useState } from 'react'

import styles from './ProductCard.module.scss'

interface ProductCardProps {
  name: string
  price: number
  category: string
  imageUrl: string
  inStock: boolean
}

export function ProductCard({ name, price, category, imageUrl, inStock }: ProductCardProps) {
  const [fav, setFav] = useState(false)

  return (
    <article className={styles.card}>
      <div className={styles.media}>
        <img src={imageUrl} alt={name} loading="lazy" />
        {!inStock && <span className={styles.sold}>Sold out</span>}
      </div>

      <div className={styles.body}>
        <span className={styles.category}>{category}</span>
        <h3 className={styles.name}>{name}</h3>
        <div className={styles.row}>
          <span className={styles.price}>${price.toLocaleString()}</span>
          <button
            type="button"
            className={clsx(styles.fav, fav && styles.active)}
            aria-pressed={fav}
            aria-label="Favorite"
            onClick={() => setFav((f) => !f)}
          >
            {fav ? '♥' : '♡'}
          </button>
        </div>
      </div>
    </article>
  )
}
```

## 4. Lay the list out responsively {#list}

Put the list grid in `App.module.scss`. With `auto-fill` + `minmax`, the column count changes automatically with the screen width.

```scss title="src/App.module.scss"
.list {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
  gap: 16px;
  padding: 16px;
}
```

```tsx title="src/App.tsx (finished)"
import products from './data/products.json'

import styles from './App.module.scss'
import { ProductCard } from './components/ProductCard/ProductCard'

function App() {
  return (
    <div className={styles.list}>
      {products.map((product) => (
        <ProductCard
          key={product.id}
          name={product.name}
          price={product.price}
          category={product.category}
          imageUrl={product.imageUrl}
          inStock={product.inStock}
        />
      ))}
    </div>
  )
}

export default App
```

Save, and the plain list becomes the **card list** you saw at the start. Change the window width and the column count changes; switch your OS to dark and the colors switch. With this, everything in this part has come together.
