## The copy itself is one line {#clipboard}

Copying is a browser feature, and what you write is effectively one line.

```ts title="Copy"
await navigator.clipboard.writeText('the text you want to copy')
```

`writeText` is **asynchronous** (a task that might not finish right away), so you add `await`. That means you add `async` to the function that calls it.

## Show that it was pressed {#feedback}

Copying finishes in an instant, so as-is you can't tell "did it work?" To **change the display just after a press**, hold a `boolean` called `copied` in state.

```tsx
const [copied, setCopied] = useState(false)
//     ↑        ↑                    ↑
//     │        │                    └─ initial value. Nothing copied yet
//     │        └─ the function that switches the display
//     └─ true / false for "did we just copy?"
```

While `copied` is `true`, make the label "Copied ✓," and after a moment set it back to `false`.

## The CopyButton itself {#copy-body}

Create a new `src/components/CopyButton/CopyButton.tsx` and paste this in.

```tsx title="src/components/CopyButton/CopyButton.tsx (new file, full)"
import { useState } from 'react'

export function CopyButton({ text }: { text: string }) {
  const [copied, setCopied] = useState(false)

  async function copy() {
    await navigator.clipboard.writeText(text)
    setCopied(true)
    window.setTimeout(() => setCopied(false), 1500)
  }

  return (
    <button type="button" onClick={copy}>
      {copied ? 'Copied ✓' : 'Copy'}
    </button>
  )
}
```

The inside of `copy` is three steps: (1) copy with `writeText`, (2) change the display with `setCopied(true)`, (3) set it back to `false` after 1.5 seconds with `setTimeout`. The label switches between the two with the `copied ? … : …` ternary operator.

<Callout type="warn" title="The condition it works: https or localhost">

`navigator.clipboard` **only works in a secure context (`https` or `localhost`)**. It works on `localhost:5173` during development. Be aware that it may not work on a `file://` page you opened directly, or on `http://` in production.

</Callout>

## Practical notes {#notes}

- **Don't make it too short or too long**: around `1500` (1.5 seconds) is a good target. Too short and it isn't seen; too long and it looks like it isn't resetting.
- **Consider failure too**: if permission is denied, `writeText` fails. For a production-grade version it is considerate to show "Couldn't copy" with `try / catch` (omitted in the demo).
