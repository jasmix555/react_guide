## Two states: "confirmed" and "preview" {#state}

The trick to a star rating is to **think of the displayed value as two separate values**.

- `value` … The rating **confirmed** by a click. The parent owns it.
- `hover` … A **temporary preview** of wherever the mouse currently is. `0` when nothing is hovered.

Then, for display, use "the preview while hovering, otherwise the confirmed value." This one line is the key.

```tsx
const shown = hover || value
```

When `hover` is `0` (falsy), `value` is used; while you hover, `hover` takes priority ([short-circuit evaluation](/guide/javascript/ternary-short-circuit)).

## The StarRating component {#body}

Create `src/components/StarRating/StarRating.tsx` as a new file and paste in this full source.

```tsx title="src/components/StarRating/StarRating.tsx (new file, full source)"
import { useState } from 'react'

interface StarRatingProps {
  value: number
  onChange: (value: number) => void
  max?: number
}

export function StarRating({ value, onChange, max = 5 }: StarRatingProps) {
  const [hover, setHover] = useState(0)
  const shown = hover || value

  return (
    <div role="radiogroup" aria-label="Rating">
      {Array.from({ length: max }, (_, i) => i + 1).map((n) => (
        <button
          key={n}
          type="button"
          role="radio"
          aria-checked={n === value}
          aria-label={`${n} stars`}
          onClick={() => onChange(n)}
          onMouseEnter={() => setHover(n)}
          onMouseLeave={() => setHover(0)}
        >
          {n <= shown ? '★' : '☆'}
        </button>
      ))}
    </div>
  )
}
```

There are two things to notice. `Array.from({ length: max }, (_, i) => i + 1)` builds `[1, 2, 3, 4, 5]` and lays out the stars. Each star is filled (★) when `n <= shown`, and empty (☆) otherwise.

<Callout type="mistake" title="Don't make the stars divs">

If you build the stars with `<span>` or `<div>` and only add `onClick`, they can't be chosen with the keyboard. **Make them `<button>`s** and you can move between them with Tab and press them with Enter. Adding `role="radio"` and `aria-checked` also tells screen readers which of the 5 levels is selected.

</Callout>
