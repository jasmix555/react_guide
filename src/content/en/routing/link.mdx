## `<a>` reloads the whole page {#why-link}

On an LP, a link was `<a href="...">`. That tells the browser to **open that page from scratch**. Do this in an SPA and **the whole app reloads** — it goes blank and then loads everything again. Any state you were holding (favorites and such) is wiped out too.

In react-router, you use **`<Link>`** instead. `<Link>` doesn't reload the page; it **swaps only the contents that need to change**. It's fast, and state is preserved.

```tsx
import { Link } from 'react-router-dom'

<Link to="/product/p01">See details</Link>
```

```tsx
<Link to="/product/p01">See details</Link>
//    ↑
//    └─ the destination URL (to, not href)
```

The key point is using **`to`** instead of `href`. It looks like an ordinary link, but clicking it doesn't cause a reload.

## NavLink: highlight the page you're on {#navlink}

When you want to highlight "the page you're on" in the nav, use **`NavLink`** instead of `<Link>`. `NavLink` tells you "am I currently at this link's destination (`isActive`)?", and you use that to switch the class.

```tsx
import { NavLink } from 'react-router-dom'

<NavLink
  to="/favorites"
  className={({ isActive }) => (isActive ? styles.active : styles.link)}
>
  Favorites
</NavLink>
```

You can pass a **function** to `className`, and if its `isActive` argument is `true`, you apply `styles.active`. That's the behavior where only the link for the current page changes color.

## Break it on purpose: use `<a>` instead of Link {#break}

Let's feel the difference. Write a link in the product list with `<a>` instead of `<Link>`.

```tsx title="Deliberately using an a tag"
<a href="/product/p01">See details</a>
```

When you click it, the screen **flashes blank for a moment** and then reloads (a full page reload). If you were holding any state, that's wiped out too. Switch back to `<Link to="/product/p01">` and the white flicker is gone — only the contents smoothly swap. **Inside an SPA, links are `<Link>`** — this is why.

## Syntax catalog: Link and NavLink {#catalog}

```tsx
// normal navigation
<Link to="/">To the list</Link>
<Link to={`/product/${product.id}`}>Details</Link>

// highlight the page you're on
<NavLink to="/favorites" className={({ isActive }) => (isActive ? styles.active : styles.link)}>
  Favorites
</NavLink>
```

## When things don't work {#trouble}

- **The screen flashes blank on click** … You're using `<a href>`. Change it to `<Link to>`.
- **`to` has no effect** … Did you write `<Link href>`? `<Link>` uses `to`, not `href`.
- **Links to external sites** … For navigating to another site (`https://...`), a plain `<a href>` is actually fine. `<Link>` is for navigation within the app.
