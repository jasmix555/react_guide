## Install {#install}

Swiper is a single package. Because it affects how the screen behaves, don't add `-D` ([put it in dependencies](/libraries/npm-install-writes)).

```bash
npm install swiper
```

The React components (`swiper/react`) and the type definitions are both bundled into the package. You don't need to install `@types/*` separately ([the types are not a separate package](/libraries/types-packages)).

## Import from React {#import}

Import the slider itself, `Swiper`, and the individual slide, `SwiperSlide`, from `swiper/react`.

```tsx
import { Swiper, SwiperSlide } from 'swiper/react'
```

## Don't forget the CSS {#css}

Swiper keeps **its appearance CSS separate**. If you don't load it, the slides look stacked vertically and you panic thinking "it's not working!" — **this is the most common stumble**. Load the base CSS once, at the top of your component.

```tsx
import 'swiper/css'
```

<Callout type="mistake" title="When it looks broken, suspect a missing CSS import">

When "all the slides line up vertically" or "I can't swipe sideways," it's usually a missing `import 'swiper/css'`. When you use arrows or dots, you also add their CSS (`swiper/css/navigation`, and so on) — we cover that on the next page, about modules.

</Callout>
