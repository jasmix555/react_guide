## Full review of this part {#recap}

You can now assemble sliders and carousels with touch gestures using Swiper. Here are the key points.

- **Setup** … after `npm install swiper`, **don't forget `import 'swiper/css'`** (the number one cause of a broken-looking layout).
- **Basics** … outer `Swiper` + `SwiperSlide`s inside. `slidesPerView` / `spaceBetween` / `loop` are the basic settings. Lay out a list with `map` + `key`.
- **Modules** … import from `swiper/modules`, pass to `modules={[...]}`, and add the CSS too. Navigation, Pagination, Autoplay, A11y.
- **Responsive** … switch the number of slides with `breakpoints` (min-width).
- **Accessibility** … for autoplay, use `useReducedMotion` and turn it off when the reduce setting is on.
