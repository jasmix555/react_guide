## whileHover / whileTap {#while}

Where `initial` / `animate` describe "the motion on mount," **`whileHover`** and **`whileTap`** describe the state **while** you are doing that action. Let go or move the pointer away and it returns to normal automatically.

```tsx
import { motion } from 'motion/react'

<motion.button
  whileHover={{ scale: 1.06 }} // slightly bigger while hovered
  whileTap={{ scale: 0.94 }} // slightly smaller while pressed
  transition={{ type: 'spring', stiffness: 400, damping: 20 }}
>
  Hover / press
</motion.button>
```

- **`whileHover={{ scale: 1.06 }}`** … 1.06x only while the pointer is over it. Move away and it returns.
- **`whileTap={{ scale: 0.94 }}`** … 0.94x only while pressed. Release and it returns.

"Sinks a little when pressed" gives your finger the feedback that **the press registered**. It is close to CSS `:hover`, but because it springs back it has a softer feel.

## Don't overdo it {#restraint}

Keep the reaction **small** by default. Around `scale: 1.06` (6%) is plenty. Big movements like `1.5` get noisy and make the button harder to press. "Barely noticeable unless someone points it out" is just about the right amount.

## When it doesn't work {#trouble}

- **It won't return** … `whileHover` / `whileTap` are "while doing" states. Check that you aren't pinning the element with `animate`.
- **whileHover doesn't fire on mobile** … touch has no hover. For reactions you also need on mobile, use `whileTap`.
