## Full review of this part {#recap}

With GSAP, you can now build scroll-linked motion and sequenced effects. Here are the key points.

- **useGSAP** … inside `useGSAP(() => { ... }, { scope })`, write `gsap.to` / `from` / `fromTo`. Cleanup and StrictMode are automatic, and `scope` limits selectors to inside the box.
- **timeline** … chain onto `gsap.timeline()` to play in order. Create overlaps and gaps with the position parameter (`'-=0.2'` / `'+=0.1'`). Remember it in a `ref` and you can control it with `restart` and friends.
- **ScrollTrigger** … `registerPlugin` first, then add `scrollTrigger`. How to read `start` / `end`, plus `scrub` (sync), `toggleActions` (play when visible), `pin` (fix in place), and `markers` (debug).
- **matchMedia** … be considerate of reduced-motion with `gsap.matchMedia()`. Remove only the motion, keep the information.
