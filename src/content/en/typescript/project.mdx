## The Product type in one place {#type}

First, gather the product shape into `src/types/product.ts` (the one we built on the [Product type page](/guide/typescript/product-type)).

```ts title="src/types/product.ts"
export interface Product {
  id: string
  name: string
  price: number
  category: 'kitchen' | 'living' | 'outdoor'
  imageUrl: string
  tags: string[]
  inStock: boolean
}
```

## Before: props one at a time {#before}

Up through Part 5, `ProductCard` received its props one at a time. Even though a product has a "fixed shape", we were taking it apart and passing the pieces every time.

```tsx title="src/components/ProductCard/ProductCard.tsx (before)"
interface ProductCardProps {
  name: string
  price: number
  category: string
  imageUrl: string
  inStock: boolean
}

export function ProductCard({ name, price, category, imageUrl, inStock }: ProductCardProps) {
  // ...
}
```

## After: consolidate into a single Product type {#after}

Since we have the `Product` type, the props come down to **just one `product`**. The way we receive them gets cleaner too.

```tsx title="src/components/ProductCard/ProductCard.tsx (after, full file)"
import clsx from 'clsx'
import { useState } from 'react'

import type { Product } from '@/types/product'
import styles from './ProductCard.module.scss'

export function ProductCard({ product }: { product: Product }) {
  const [fav, setFav] = useState(false)

  return (
    <article className={styles.card}>
      <div className={styles.media}>
        <img src={product.imageUrl} alt={product.name} loading="lazy" />
        {!product.inStock && <span className={styles.sold}>Sold out</span>}
      </div>

      <div className={styles.body}>
        <span className={styles.category}>{product.category}</span>
        <h3 className={styles.name}>{product.name}</h3>
        <div className={styles.row}>
          <span className={styles.price}>{product.price.toLocaleString()} yen</span>
          <button
            type="button"
            className={clsx(styles.fav, fav && styles.active)}
            aria-pressed={fav}
            aria-label="Favorite"
            onClick={() => setFav((f) => !f)}
          >
            {fav ? '♥' : '♡'}
          </button>
        </div>
      </div>
    </article>
  )
}
```

You read them through `product.` — `product.name`, `product.price`, and so on. Since `product` is of type `Product`, `product.nam` (a typo) is stopped with a red underline, and autocomplete works too.

## Type the list too {#list}

Read `products.json` as `Product[]` and pass `product` straight to each card. The call gets shorter, too.

```tsx title="src/App.tsx"
import products from './data/products.json'

import type { Product } from './types/product'
import styles from './App.module.scss'
import { ProductCard } from './components/ProductCard/ProductCard'

const list = products as Product[]

function App() {
  return (
    <div className={styles.list}>
      {list.map((product) => (
        <ProductCard key={product.id} product={product} />
      ))}
    </div>
  )
}

export default App
```

You pass just the one `product={product}`. Compared to the before version where you wrote out five — `name={...} price={...}` — you can't forget to pass one.
