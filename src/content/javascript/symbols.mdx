## 名前が分からない記号は調べられない {#why}

プログラムには、アルファベットの命令だけでなく **記号** がたくさん出てきます。`!!` や `%` を初めて見たとき、多くの人がつまずくのは「**その記号の名前が分からないので、検索すらできない**」ことです。`for` や `map` は名前で調べられますが、`!!` を検索するのは難しい。

このページは、**見た目から意味を引ける早見表**です。ここまでの記号をいちど整理し、まだ説明していない「よく見るのに名前が分からない」記号を、手を動かしながら覚えます。全部を暗記する必要はありません。「見たことがある」「調べ方が分かる」状態になれば十分です。

<Callout type="analogy">

道路標識と同じです。ひとつずつ意味を知っていれば読めますが、知らない標識は「何か注意しろと言っている」ことしか分かりません。記号も、いちど意味を知れば毎回すっと読めるようになります。

</Callout>

## すでに出てきた記号（早見） {#seen}

ここまでのパートで意味をやった記号です。忘れたらリンク先に戻ってください。

- `=>` … アロー関数（関数を短く書く矢印）。[アロー関数](/guide/javascript/arrow-functions)
- `` ` `` … テンプレートリテラル（文字列の中に値を埋める）。[テンプレートリテラル](/guide/javascript/template-literals)
- `...` … スプレッド／rest（配列やオブジェクトを展開する・集める）。[スプレッドと rest](/guide/javascript/spread-rest)
- `? :` … 三項演算子（二択で選ぶ）。[三項演算子と短絡評価](/guide/javascript/ternary-short-circuit)
- `&&` … 「真のときだけ返す」。React では `条件 && 表示` で「条件が真のときだけ表示」に使います（Part 7 で詳しくやります）
- `||` … 「偽なら代わりを返す」（既定値）
- `?.` … 無いかもしれない経路を安全にたどる。[?. と ??](/guide/javascript/optional-chaining)
- `??` … `null` / `undefined` のときだけ既定値

ここから下は、まだ説明していない記号です。

## ! ：反対にする {#not}

`!` は「**否定**」、値の真偽を **反対** にします。`true` は `false` に、`false` は `true` になります。

```js
console.log(!true)  // false
console.log(!false) // true

const isOpen = false
if (!isOpen) console.log('閉じています') // → 閉じています（!false が true）
```

`if (!isOpen)` は「`isOpen` で**なければ**」という意味です。「開いていないとき」を素直に書けます。`!` は truthy / falsy の判定にもかかり、`!''`（空文字は falsy）は `true`、`!'あ'`（中身のある文字列は truthy）は `false` になります。

<JsNote feature="! は「っぽさ」を反転させる">

`!値` は、まず値が truthy か falsy かを判定し、その **逆** を `true` / `false` で返します。`!0` は `true`（`0` は falsy）、`!'text'` は `false`（文字列は truthy）です。[truthy と falsy](/guide/javascript/truthy-falsy) の 6 つを思い出すと読めます。

</JsNote>

## !! ：どんな値も true / false に変換する {#double-not}

`!` を **2 回** 重ねた `!!` は、「反対の反対」＝元の真偽に戻ります。ただし戻り値は必ず `true` か `false`。つまり `!!` は「**どんな値も、本物の `true` / `false` に変換する**」記号です。

```js
console.log(!!'text') // true   （文字列は truthy → true）
console.log(!!'')     // false  （空文字は falsy → false）
console.log(!!0)      // false  （0 は falsy → false）
console.log(!!42)     // true
```

`!!` を、部品に分けて名前を付けます。

```js
   !!value
// ↑ ↑
// │ └─ どんな値でも受け取る（文字列・数値・null…）
// └─ ! を 2 回。反転の反転で、必ず true / false になる
```

- **`!`** … 真偽を**反転**（`true`↔`false`。truthy / falsy も判定して反転する）
- **`!!`** … `!` を 2 回。反転の反転で、**どんな値も必ず `true` / `false`** になる
- 用途：`&&` の左を真偽値にして `0` の画面漏れを防ぐ（`!!items.length`）

なぜわざわざ変換するのでしょう。たとえば「**中身のある値かどうか**」を `true` / `false` のフラグとして持ちたいときです。とくに [三項演算子と短絡評価](/guide/javascript/ternary-short-circuit) でやった「`0 && …` が `0` を返して画面に漏れる」罠を、`!!` で防げます。`items.length`（数値）をそのまま `&&` の左に置くと `0` が漏れますが、`!!items.length` にすれば `0` は `false` になり、漏れません。

<Together
  task="user.nickname（空文字 '' のことも、名前が入っていることもある）から、「ニックネームを持っているか」を true / false で表す hasNickname を作ってみてください。コンソールで '' と 'たろう' の両方を試しましょう。"
  hint="!! を頭に付けると、文字列を true / false に変換できます。"
>

```js
const user = { nickname: '' }
const hasNickname = !!user.nickname
console.log(hasNickname) // false（'' は falsy）

const user2 = { nickname: 'たろう' }
console.log(!!user2.nickname) // true（中身がある文字列は truthy）
```

`!!user.nickname` は、空文字なら `false`、中身があれば `true` になります。「値そのもの」ではなく「**あるか・ないかの真偽**」を持ちたいときに `!!` を使います。

</Together>

## % ：割った余り {#modulo}

`%` は割り算の **余り** を出します（割った商ではありません）。`10 % 3` は「10 を 3 で割った余り」＝ `1` です。

```js
console.log(10 % 3) // 1  （10 ÷ 3 = 3 あまり 1）
console.log(10 % 2) // 0  （割り切れる）
console.log(7 % 2)  // 1  （割り切れない）
```

`%` も、部品に分けて名前を付けておきます。

```js
   n % 2
// ↑ ↑ ↑
// │ │ └─ 割る数
// │ └─ % は「割った余り」を出す（商ではない）
// └─ 割られる数
```

- **`%`** … 割り算の**余り**（商ではない）。`10 % 3` は `1`
- **`n % 2 === 0`** … 偶数判定（余りが 0）
- **`index % 3`** … `0,1,2,0,1,2…` と循環。列数などに使える

一番よく使うのが **偶数・奇数の判定** です。「2 で割った余りが 0 なら偶数」。一覧を 1 行おきに色を変える（しま模様）ときなどに使います。

```js
const n = 4
console.log(n % 2 === 0 ? '偶数' : '奇数') // 偶数
```

`%` は「**繰り返し**」にも使えます。`0, 1, 2, 0, 1, 2 …` と循環させたいとき、`index % 3` は必ず `0〜2` の範囲をぐるぐる回ります。3 列のグリッドで「何列目か」を出すときなどに便利です（React での一覧表示は Part 7 で詳しくやります）。

<Together
  task="一覧の index（0, 1, 2, 3, 4 …）に対して、偶数番目なら '白'、奇数番目なら 'グレー' を返す stripe を、% を使って書いてみてください。"
  hint="index % 2 === 0 が偶数番目。三項演算子で色を選びます。"
>

```js
const index = 3
const stripe = index % 2 === 0 ? '白' : 'グレー'
console.log(stripe) // グレー（3 は奇数番目）
```

`index % 2` は `0`（偶数番目）か `1`（奇数番目）になります。それを `=== 0` で判定して色を選びました。しま模様や「3 個ごとに区切る」といった処理は、この `%` が土台です。

</Together>

## わざと壊す：== は型が違っても一致する {#break-loose-equality}

比較には、イコールが 2 個の `==` と 3 個の `===` があります。見た目が似ていますが、**動きが違います**。`==` は「**型が違っても、変換してから比べる**」ため、直感に反する結果を生みます。コンソールで確かめます。

```js
console.log(0 == '')    // true   ← 数値の 0 と空文字が「等しい」
console.log(0 == '0')   // true   ← 0 と 文字の '0' が「等しい」
console.log('' == '0')  // false  ← でもこの 2 つは「等しくない」
```

`0` と `''` が等しく、`0` と `'0'` も等しいのに、`''` と `'0'` は等しくない——**一貫しません**。`==` が裏で型を変換しているせいで、こういう予想外の一致が起きます。バグの温床です。

直し方はかんたんで、いつも **`===`（イコール 3 個）** を使います。`===` は「**値も型も同じときだけ** 等しい」と判定するので、変換による事故が起きません。

```js
console.log(0 === '')   // false（型が違う＝等しくない。素直）
console.log(0 === 0)    // true
```

比較の記号は、次の 5 種類を覚えておけば足ります。

| 記号 | 意味 |
|---|---|
| `===` | 値も型も同じ（**これを使う**） |
| `!==` | 値か型が違う（`===` の反対） |
| `>` `<` | より大きい／より小さい |
| `>=` `<=` | 以上／以下 |
| `==` `!=` | ゆるい比較（型を変換して比べる・**使わない**） |

<Callout type="warn">

`==` / `!=`（イコール 2 個）は、型を勝手に変換して予想外の一致を作ります。新しいコードでは必ず `===` / `!==`（イコール 3 個）を使ってください。[今は知らなくていいもの](/guide/javascript/not-yet) でも「`==` は避ける」と決めています。

</Callout>

## 見かけたら読めればいい：論理代入 ||= ??= &&= {#logical-assign}

`||=` `??=` `&&=` は、既存コードで見かけることがある短縮記号です。**書けなくても、読めれば十分**です。中身は、すでにやった短絡評価の「代入版」にすぎません。

- `x ||= y` … `x = x || y` の短縮。`x` が falsy なら `y` を入れる
- `x ??= y` … `x = x ?? y` の短縮。`x` が `null` / `undefined` のときだけ `y` を入れる
- `x &&= y` … `x = x && y` の短縮。`x` が truthy のときだけ `y` を入れる

```js
let name = ''
name ||= '名無し' // name が falsy なので '名無し' が入る
console.log(name) // 名無し
```

意味は [三項演算子と短絡評価](/guide/javascript/ternary-short-circuit) と [?. と ??](/guide/javascript/optional-chaining) がそのまま効きます。「あの短絡評価に `=` が付いた代入版だ」と読めれば OK です。無理に自分で使う必要はありません。

## 書き方カタログ：記号の早見 {#catalog}

このページで出てきた記号を、使う形で並べます。「見た目→意味」を思い出す手がかりにしてください。

```js
!isOpen      // ! ：真偽を反転（開いていない、を素直に書く）
!!value      // !! ：どんな値も true / false に変換
n % 2 === 0  // % ：余りで偶数判定
a === b      // === ：値も型も同じか（比較はこれを使う）
a !== b      // !== ：=== の反対
x ?? 0       // ?? ：null / undefined のときだけ既定値
```

比較は事故らない `===` / `!==` を使い、`&&` の左が数値になるなら `!!` で真偽値に変換する——この 2 つを押さえれば、日々のコードで詰まりません。

## うちの標準 {#standard}

<Std
  decision="比較は必ず === / !== を使う。真偽値が欲しい場面では !! で明示的に変換する"
  alt="論理代入（||= など）は、読めれば十分で、無理に使わなくて構いません。まずは元の x = x || y の形で意図が伝わるほうを選びます。"

記号は「**読めること**」が最優先です。書くときは、意図が伝わるものを選びます。比較は事故らない `===` / `!==`。`&&` の左が数値になるなら `!!` や `> 0` で真偽値にする。`%` は「余り」であって割り算ではない、と押さえておけば、日々のコードで詰まりません。

</Std>
