## なぜアロー関数を覚えるのか {#why}

React のコードでは、関数を「その場でちょっと書く」場面がとても多いです。ボタンを押したときの処理、リストの各要素に対する処理——こういう小さな関数を短く書くために、**アロー関数**という書き方を使います。中身は今まで書いてきた `function` と同じですが、見た目が短くなります。

まず、同じ処理を 2 通りで書いて並べます。

```js
// これまでの function
function double(n) {
  return n * 2
}

// アロー関数（同じ意味）
const double = (n) => {
  return n * 2
}
```

やっていることは同じです。`function double(...)` が `const double = (...) => ...` に変わっただけ。`function` という単語が消え、引数の後ろに `=>`（矢印）が付きます。

いちど、アロー関数の 1 行を部品に分けて名前を付けておきます。

```js
const add = (a, b) => a + b
//    ↑     ↑        ↑  ↑
//    │     │        │  └─ 本体。この式の結果がそのまま戻り値になる
//    │     │        └─ => 矢印。左が引数、右が中身
//    │     └─ 引数リスト。2 つ以上は ( ) で囲む
//    └─ 関数の名前（const に入れて持ち運ぶ）
```

- **`add`** … 関数の名前。`const` に入れて持ち運ぶ
- **`(a, b)`** … 引数リスト。受け取る値。0 個なら `()`、1 個なら `()` を省ける
- **`=>`** … アロー（矢印）。左が引数、右が中身
- **`a + b`** … 本体。波かっこが無いので、この式の結果が**そのまま戻り値**になる

<JsNote feature="() => {} がアロー関数">

`() => {}` は「引数 `()` を受け取って、`{}` の中の処理をする関数」という意味です。`=>` の左が引数、右が中身です。名前を付けたいときは `const double = () => {}` のように `const` に入れます。

</JsNote>

## ステップ 1：引数が 1 つなら かっこを省ける {#one-arg}

引数が 1 つだけのときは、引数を囲むかっこ `()` を省けます。

```js
const double = (n) => {
  return n * 2
}

// 引数が1つなら () を省ける
const double2 = n => {
  return n * 2
}
```

どちらも同じです。React のコードでは省いた形をよく見ます。ただし、引数が 0 個や 2 個以上のときは `()` が必要です（`() =>`, `(a, b) =>`）。

## ステップ 2：一行なら return も波かっこも省ける {#implicit-return}

中身が「値を 1 つ返すだけ」なら、`{}` と `return` の両方を省いて、もっと短く書けます。

```js
// 波かっこと return を省いた形
const double = n => n * 2

console.log(double(5)) // 10
```

`n => n * 2` は「`n` を受け取って `n * 2` を返す」という意味です。`{}` が無いときは、`=>` の右の式が**そのまま戻り値**になります。React で `map` を使うときなどに、この短い形が主役になります。

## わざと壊す：波かっこを付けると return が要る {#break-missing-return}

一番ハマるのがこれです。**波かっこ `{}` を付けたのに `return` を書き忘れる**と、エラーは出ないのに `undefined` が返ります。コンソールで試します。

```js
const double = n => {
  n * 2 // return を書いていない
}

console.log(double(5)) // undefined
```

`10` を期待したのに `undefined` です。エラーも出ません。理由はこうです。`=>` の後ろに `{}` を書くと、それは「ここから処理を書きますよ」という合図になり、**値を返すには `return` が必要**になります。`n * 2` を計算しただけで、返していないので `undefined` になったのです。

直し方は 2 つ。波かっこを消して一行にするか、`return` を足すかです。

```js
const double = n => n * 2 // 波かっこを消す（自動で返る）
// または
const double = n => {
  return n * 2 // 波かっこを残すなら return を書く
}
```

<Callout type="warn">

「関数を書いたのに `undefined` になる」ときは、まず**波かっこの中で `return` を書き忘れていないか**を疑ってください。エラーが出ないぶん、原因に気づきにくい定番のバグです。

</Callout>

## 書き方カタログ：アロー関数のいろいろな形 {#catalog}

引数の数と「返すだけか・処理が続くか」で、書き方が変わります。よく見る形を並べます。

```js
const hello = () => 'やあ'             // 引数なし → () は必須
const double = n => n * 2              // 引数 1 つ → () を省ける
const add = (a, b) => a + b           // 引数 2 つ以上 → () で囲む
const withTax = price => price * 1.1  // 返すだけ → {} と return を省ける
const log = (msg) => {                // 処理が複数行 → {} で囲む
  console.log(msg)
  return msg                          // {} を付けたら return が要る
}
```

「返すだけの一行」は波かっこも `return` も省く、「処理が複数行」なら波かっこ＋`return`——この 2 つを押さえれば、React で出てくる形はほぼ読めます。

## うちの標準 {#standard}

<Std
  decision="名前付きの関数もアロー関数（const 名 = () => …）で統一する"
  alt="ファイルの一番外側に置くコンポーネントなど、巻き上げ（先に書いても動く性質）が欲しい場面では function 宣言も使います。迷ったらアローで揃えて構いません。"
>

React のコードはアロー関数が主流です。書き方を 1 つに揃えておくと、読むときに迷いません。「返すだけの一行」は波かっこ・`return` を省き、処理が複数行なら波かっこ＋`return` を書く、と決めておきます。

</Std>

## もっと知りたい人へ {#deeper}

<Deeper title="this の話（今は気にしなくていい）">

アロー関数には「`this` を自分で作り直さない」という性質があり、昔の jQuery で `var self = this` と書いていた回避策が要らなくなります。ただ、React の関数コンポーネントでは `this` をほとんど使わないので、**今は「アロー関数は this まわりが素直」とだけ覚えておけば十分**です。必要になったら戻ってきてください。

</Deeper>

## うまくいかないとき {#trouble}

- **関数の結果が `undefined`** … 波かっこ `{}` の中で `return` を書き忘れています。一行にするか `return` を足します。
- **`Unexpected token` などの構文エラー** … 引数が 2 つ以上なのに `()` で囲んでいない、`=>` を `->` や `=<` と打ち間違えている、などをまず確認します。
